# JPRX

Persistent identifiers for the JPRX ontology and knowledge graph of robotic construction processes
(enabler ontology re-engineered from Ng et al. 2022, instantiated with deployed robotic processes in Japan).

- Ontology: https://w3id.org/jprx/ontology (namespace `https://w3id.org/jprx/ontology#`)
- Versioned ontology: https://w3id.org/jprx/ontology/2.0.0
- Knowledge graph (anonymised public version): https://w3id.org/jprx/kg
- Project page: https://charmings33.github.io/processatlas/
