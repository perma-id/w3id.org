# AKG behavioral ontology

Persistent identifier for the AKG behavioral ontology, namespace `https://w3id.org/akg/behavioral#`.

* `https://w3id.org/akg/behavioral` redirects to the HTML documentation, or to the Turtle file for RDF clients (`Accept: text/turtle`).
* Source: https://github.com/gurukraj/akg-uml-behavioral
