# /humeta/

Permanent identifiers for HuMeta, part of STEMEd+ Commons: the records of the
HuMeta Instrument Library (instruments, their versions and items, shared
constructs, and theories and frameworks used in education and social science
research) and the HuMeta metadata-code scheme.

`https://w3id.org/humeta/` redirects to <https://jlib271.github.io/humeta-library/>.

| Identifier | Names |
| --- | --- |
| `https://w3id.org/humeta/instrument/hmi0004` | an instrument |
| `https://w3id.org/humeta/instrument/hmi0004.1` | one version of an instrument |
| `https://w3id.org/humeta/instrument/hmi0004/item/q05` | one item, the same in every version that has it |
| `https://w3id.org/humeta/construct/hmc0024` | a shared construct |
| `https://w3id.org/humeta/framework/hmf0038` | a theory or framework |
| `https://w3id.org/humeta/instrument`, `.../construct`, `.../framework` | the list of each kind of record |
| `https://w3id.org/humeta/metadata-code` | the HuMeta metadata-code scheme |

Identifiers are opaque (a type letter and a number) and are never reassigned or
deleted. An instrument identifier requested with `Accept: application/json`
returns the instrument's record as JSON.

Identifier policy: <https://github.com/JLib271/humeta-library/blob/main/IDENTIFIERS.md>

Source: <https://github.com/JLib271/humeta-library>
