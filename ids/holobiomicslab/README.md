# Holobiomics Lab — artefact identifiers

Permanent identifiers for artefacts published by the Holobiomics Lab
(CNRS / Université Côte d'Azur).

## Namespaces

* `https://w3id.org/holobiomicslab/asb-skill/` — ASB Skill Collections: released
  collections, their registry and the contribution leaderboards.
  * `…/asb-skill/registry` — the catalogue (JSON-LD).
  * `…/asb-skill/collection/<slug>/v<N>` — one released collection.
  * `…/asb-skill/leaderboard/<id>` — a contribution leaderboard (JSON-LD).
