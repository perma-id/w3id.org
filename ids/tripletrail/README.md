# /tripletrail/

Permanent namespace IRIs for [TripleTrail](https://tripletrail.eu/), an RDF
triple store with SPARQL, GeoSPARQL and SHACL.

Each namespace is a hash namespace, such as `https://w3id.org/tripletrail/st#`
for the spatial functions or `https://w3id.org/tripletrail/pgr#` for routing.
`https://w3id.org/tripletrail/NAME` redirects (303) to the documentation at
`https://tripletrail.eu/ns/NAME/`, or to `https://tripletrail.eu/ns/NAME.ttl`
when the client asks for `text/turtle`. `https://w3id.org/tripletrail/`
redirects to the list of namespaces at <https://tripletrail.eu/ns/>.
