# /aoc-dfo/

Persistent identifiers for AOC-DFO, the AOC Data Flow Ontology: a BFO/CCO ontology of USAF Air
Operations Center data flows, built from public sources.

`https://w3id.org/aoc-dfo/` and the IRIs under it redirect to <https://semanticarchitectures.github.io/aoc-dfo/>.
Browsers get HTML; other clients get Turtle.

| IRI | What it names |
| --- | --- |
| `https://w3id.org/aoc-dfo/ontology#…` | AOC-DFO classes and properties |
| `https://w3id.org/aoc-dfo/aoc-<module>` | An ontology module, e.g. `aoc-flows` |
| `https://w3id.org/aoc-dfo/<x.y.z>/<doc>` | A module or the full ontology at a release |

Source and documentation: <https://github.com/semanticarchitectures/aoc-dfo>
