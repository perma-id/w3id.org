# semanticClimate Permanent Identifiers

## Namespace

https://w3id.org/semanticclimate/

## Description

semanticClimate is an open-source initiative developing tools and resources for extracting, organising, linking, and exploring scientific knowledge from scholarly literature.

This namespace provides persistent identifiers for semanticClimate knowledge resources, including knowledge graphs, vocabularies, ontologies, and related semantic resources.

## Purpose

The namespace supports:

- Persistent identification of semanticClimate knowledge resources.
- Interoperability and reuse of RDF-based knowledge graphs.
- Linking scientific literature with concepts, vocabularies, and semantic resources.
- Development and sharing of open, reproducible scientific knowledge infrastructure.

## URI Structure

The namespace may be extended with resource-specific identifiers:

- `/kg/` — Knowledge graphs
- `/ontology/` — Ontologies
- `/vocabulary/` — Controlled vocabularies
- `/concept/` — Concept identifiers
