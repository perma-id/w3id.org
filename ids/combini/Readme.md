# COMBINI Project: Resources and Results

This namespace hosts persistent identifiers (PIDs) for resources related to the **COMBINI** project — **CO**nnecting Co**mplementary** Medicine evidence and **BI**ological k**N**owledge to support **I**ntegrative health.

🔗 Project site: [combini-hub.github.io](https://combini-hub.github.io/)

---

## Persistent Identifiers

This namespace redirects requests under `w3id.org/combini/...` to their canonical locations, providing stable, citable URLs for project resources that are independent of where the underlying files are hosted.

| Path | Redirects to | Description |
|---|---|---|
| `/semkraph/license` | [`license.ttl`](https://github.com/COMBINI-Hub/semkraphkg-pipeline/blob/main/license.ttl) (raw) | License for the SemKraph knowledge graph |
| `/semkraph/metadata` | [`semkraph-metadata.ttl`](https://github.com/COMBINI-Hub/semkraphkg-pipeline/blob/main/semkraph-metadata.ttl) (raw) | DCAT metadata for SemKraph |
| `/semkraph/source_files` | [Zenodo record](https://doi.org/10.5281/zenodo.20735733) | SemKraph source files |
| `/semkraph/output_files` | [Zenodo record](https://doi.org/10.5281/zenodo.21652814) | SemKraph output files |
| `/semkraph` | [DCAT/SHACL Visualizer](https://hbcesar.github.io/simple-dcat-visualizer/?url=https://github.com/COMBINI-Hub/semkraphkg-pipeline/blob/main/semkraph-metadata.ttl) | Human-readable view of the SemKraph metadata |
| `/*` (any other path) | [combini-hub.github.io](https://combini-hub.github.io/) | Project homepage (fallback) |
