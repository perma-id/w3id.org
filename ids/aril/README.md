# /aril/

Persistent identifiers for a metadata vocabulary for animal behaviour data. Identifiers under this
namespace name the parts of the vocabulary: the model, its SHACL shapes, its terms and its error
codes.

They are frozen once minted. A term keeps its identifier through promotion and through deprecation,
so a dataset that cites one stays readable.

Registered here rather than on a project domain because the identifiers are meant to outlast any
particular hosting arrangement, and a redirect can be repointed where an identifier cannot be
rewritten.

## Redirection

`https://w3id.org/aril/...` currently redirects to `https://benoitjt-girard.github.io/aril/...`,
a placeholder while the first release is prepared. The target will change; the namespace will not.
