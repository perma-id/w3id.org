# /maktoob/

Persistent identifiers for Maktoob, the reference vocabulary of impact
management published by [Narrate](https://narrate.works/).

`https://w3id.org/maktoob/<path>` redirects (303) to
`https://narrate.works/id/<path>`, which serves each concept, collection and
the ontology as Turtle, JSON-LD or HTML.

For example, `https://w3id.org/maktoob/begrip` is the concept scheme.
