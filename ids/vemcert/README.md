# /vemcert/

Permanent identifiers for the Vemcert vocabulary: the terms used in W3C
Verifiable Credentials issued with Vemcert.

- `https://w3id.org/vemcert/v1` is the version 1 namespace (`https://w3id.org/vemcert/v1#<term>`).
  It redirects (303) to the JSON-LD context for `Accept: application/ld+json`,
  otherwise to the human-readable term reference.
- `https://w3id.org/vemcert/` redirects to the version index.

Published at <https://gasmsyteacher.github.io/vemcert-vocab/>.
