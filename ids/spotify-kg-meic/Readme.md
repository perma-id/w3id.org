# Spotify Knowledge Graph

Persistent identifiers for the Spotify Knowledge Graph project.

## Namespace

https://w3id.org/spotify-kg-meic/

## Description

This namespace is used for the custom Spotify vocabulary
and related RDF resources developed as part of the
Spotify Knowledge Graph project.
