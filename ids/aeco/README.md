# /aeco/

Permanent identifiers for the Aecoware Open Taxonomy, an open SKOS taxonomy for architecture, engineering, construction and operations.

`https://w3id.org/aeco/` redirects to <https://aecoware.github.io/aecxonomy/>. Concept IRIs such as `https://w3id.org/aeco/aeco-01008` open the explorer at that concept. RDF clients get Turtle or JSON-LD.

Repository: <https://github.com/Aecoware/aecxonomy>
