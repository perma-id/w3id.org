# /moca/

Permanent identifiers for [OpenMOCA](https://openmoca.org), an open standard for packaging digital works with their
credits, sources and the creator's terms.

| Identifier | Redirects to |
|---|---|
| `https://w3id.org/moca/schemas/...` | `https://openmoca.org/schemas/...` (JSON Schemas) |
| `https://w3id.org/moca/profiles/...` | `https://openmoca.org/profiles/...` (profiles; the site content-negotiates) |
| `https://w3id.org/moca/attestation/...` | `https://openmoca.org/spec/attestations/` (attestation statement types) |
| anything else under `/moca/` | the same path on `https://openmoca.org/` |
