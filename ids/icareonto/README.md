# /icareonto/

Permanent identifiers for iCARE Onto, a modular ontology supporting cancer survivorship, cardiovascular health and personalised education.

Namespace: <https://w3id.org/icareonto/>

Documentation and source: <https://github.com/RGU-Computing/icareonto>

Published documents: <https://rgu-computing.github.io/icareonto/>

The root IRI returns a documentation redirect for HTML requests and complete RDF documents for machine requests. Module paths resolve to individual Turtle documents. General version-path rules resolve preserved ontology and educational catalogue snapshots without a redirect change for each release.
