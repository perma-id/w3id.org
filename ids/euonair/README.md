# EUonAIR

Persistent identifiers of the EUonAIR European University alliance (https://euonair.eu), starting with the
EUonAIR AI-Ready Course Description Profile (https://github.com/euonair/course-profile).

- `https://w3id.org/euonair/course#…` — profile terms
- `https://w3id.org/euonair/course/profile/<version>` — releases
- `https://w3id.org/euonair/vocab/<scheme>/<value>` — seed vocabularies
