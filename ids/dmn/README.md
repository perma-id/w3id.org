# DMN 1.6 in RDF

Persistent identifiers for "DMN 1.6 in RDF", a draft OWL ontology, SHACL
validation set and decision table checker for DMN 1.6 (OMG). The ontology is
generated from OMG's machine-readable metamodel; the requirement rules of
Table 2, the hit policies and the normative statements of the specification are
published as data, with bridges to BPMN and ArchiMate.

This is not an OMG publication.

* Namespace: `https://w3id.org/dmn#`
* Source and issue tracker: https://github.com/jwvveen/dmn-rdf
* Siblings: [`https://w3id.org/bpmn`](https://github.com/jwvveen/bpmn-rdf) and
  [`https://w3id.org/archimate`](https://github.com/jwvveen/archimate-rdf)

RDF clients (`Accept: text/turtle`) are redirected to the Turtle files;
browsers to the repository.
