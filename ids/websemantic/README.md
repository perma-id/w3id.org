# websemantic

Persistent identifiers for the websemantic ontology: a software-agnostic semantic layer that describes scientific
software once and compiles the description into an LLM contract, an ontology with SHACL shapes and FAIR metadata.

* Homepage: https://github.com/cyrilvoyant/websemantic
* Archive: https://doi.org/10.5281/zenodo.23238902

## URIs

* `https://w3id.org/websemantic/ns` and `https://w3id.org/websemantic/ns/core`: current ontology (Turtle for RDF
  clients, documentation for browsers).
* `https://w3id.org/websemantic/ns/core/<version>` (e.g. `0.2.0`): versioned ontology from the matching Git tag.
