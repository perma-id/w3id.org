# membership — Membership Organisations Ontology

Persistent identifiers for the Membership Organisations Ontology and its SKOS codelists.
The redirects point at the project's GitHub Pages site.

| IRI | Redirects to |
|---|---|
| `https://w3id.org/membership` | the ontology: Turtle for RDF clients, HTML documentation for browsers |
| `https://w3id.org/membership/1.0.0` | version 1.0.0 of the ontology (Turtle) |
| `https://w3id.org/membership/code`, `…/code/<concept>` | the codelists (Turtle) |
| `https://w3id.org/membership/external` | declarations of the reused external terms (Turtle) |
| `https://w3id.org/membership/shapes` | SHACL shapes (Turtle) |
| `https://w3id.org/membership/mappings/<set>` | generated SSSOM mapping set (Turtle) |

Source: https://github.com/society-ontologies/membership-fraternal
