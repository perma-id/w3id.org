# SOSA/SSN Usage Observatory

This space provides a persistent w3id.org URI for the **SOSA/SSN Usage Observatory**, a knowledge graph describing how the scientific literature uses the W3C/OGC Semantic Sensor Network ontology (SOSA/SSN), together with its web explorer.

## URI redirection

The following URI and all paths beneath it redirect to the observatory:

- https://w3id.org/sosa-ssn-observatory/

The redirection uses HTTP 302 and targets:

https://ci.mines-stetienne.fr/sosa-ssn-observatory/
