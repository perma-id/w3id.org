# PHVL — Plant Health Vision-Language ontology

Persistent identifiers for the PHVL ontology: host–condition concepts that map the labels of public plant disease,
pest and weed image datasets to a common vocabulary.

- `https://w3id.org/phvl/` — the ontology (AgroPortal page; Turtle with `Accept: text/turtle`)
- `https://w3id.org/phvl/PHVL_nnnnnnn` — one concept (AgroPortal concept page)

Data and releases: https://doi.org/10.5281/zenodo.23893673
