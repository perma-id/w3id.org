# /servicefacts/

Permanent identifiers for Service Facts, open schema.org extension vocabularies for professional services.

Term IDs are hash IDs, for example `https://w3id.org/servicefacts/legal#actsFor`.

- `https://w3id.org/servicefacts/` redirects to <https://wldm-gh.github.io/servicefacts/>.
- `https://w3id.org/servicefacts/legal` redirects a browser to the documentation page, and a JSON-LD or Turtle client to the vocabulary file.
- `https://w3id.org/servicefacts/legal/0.1` does the same for the frozen 0.1 release.

Documentation: <https://wldm-gh.github.io/servicefacts/>

Source: <https://github.com/wldm-gh/servicefacts>
