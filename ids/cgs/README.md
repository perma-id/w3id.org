# /cgs/

Permanent identifiers for the Center for Geospatial Solutions (CGS).

About CGS: <https://www.lincolninst.edu/centers-initiatives/center-geospatial-solutions/>

## Redirects

`https://w3id.org/cgs/ontology/core/` redirects to
<https://cgs-earth.github.io/ontologies/>.

The rest of the path is preserved. For example,
`https://w3id.org/cgs/ontology/core/spatiotemporal/` redirects to
<https://cgs-earth.github.io/ontologies/spatiotemporal/>.
