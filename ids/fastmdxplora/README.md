# FastMDXplora

Persistent identifiers for [FastMDXplora](https://github.com/aai-research-lab/FastMDXplora),
software for automated molecular dynamics studies:

- `https://w3id.org/fastmdxplora/study/<version>`: the RO-Crate profile a
  shared FastMDXplora study keeps, for example
  `https://w3id.org/fastmdxplora/study/1.0`.
- `https://w3id.org/fastmdxplora/terms#<term>`: the terms its packing list
  uses (`role`, `phase`, `readWith` and the rest).

Both lead to the documentation, https://fastmdxplora.readthedocs.io/en/latest/sharing.html.
