# /intigraph/

Persistent identifiers for the [Intigraph](https://intigraph.ai) knowledge-graph stack:
vocabularies such as `https://w3id.org/intigraph/quechua/ns#` and the public entity IRIs
used in the stack's published data.

All paths redirect to `https://intigraph.ai/ids/<path>`, with Turtle and JSON-LD
served on request.
