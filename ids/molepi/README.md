# MOLEPI W3id repository

This repository is structured as followed:

/LLSmica - Reference to our MICA application
/Data\_requests/ - this directory will contain all of our data-request forms for the different studies.

* /LLS - Link to the LLS data request form

/MICA/ - This folder will host identifiers for our MICA applications

* VOILA/ - this is our MICA metadata portal page for VOILA
* LLS/ - this is our MICA metadata portal page for LLS
* GOTO/ - this is our MICA metadata portal page for VOILA
