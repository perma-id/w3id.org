# /ontosim-dis/

Permanent identifiers for OntoSim-Dis, an OWL 2 ontology of disease simulation models.

`https://w3id.org/ontosim-dis` redirects, by content negotiation, to the documentation or to
the ontology published at <https://paulcadiouf.github.io/ontosim-dis/>.

Source: <https://github.com/PaulCADIOUF/ontosim-dis>
