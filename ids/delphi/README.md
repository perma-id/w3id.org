# Delphi

Permanent identifiers for [Project Delphi](http://delphibio.org/).

| IRI | Redirects to |
| --- | --- |
| `https://w3id.org/delphi/ontology`, `…/ontology/<version>` and `…/ontology/<Term>` | [`ONTOLOGY.md`](https://github.com/fractastical/project-delphi-ontology/blob/main/ONTOLOGY.md) for browsers, [`delphi.ttl`](https://raw.githubusercontent.com/fractastical/project-delphi-ontology/main/delphi.ttl) otherwise |
| `https://w3id.org/delphi/resource/<kind>/<id>` | `https://scienceoracle.com/resource/<kind>/<id>` |
| anything else under `https://w3id.org/delphi/` | <https://github.com/fractastical/project-delphi-ontology> |
