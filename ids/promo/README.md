# ProMo — Process Modelling ontology

Permanent identifier namespace for the ProMo process-modelling
vocabulary and ontology graphs, developed in the ProMo14 project.

- Vocabulary: `https://w3id.org/promo#`
- Ontology graph: `https://w3id.org/promo/ontology`
- Language vocabulary: `https://w3id.org/promo/language#`
- Source code: https://github.com/heinz-preisig/ProMo14
- Published artefacts: https://heinz-preisig.github.io/ProMo-ontologies/
