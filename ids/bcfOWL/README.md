# /bcfOWL/

Permanent identifiers for bcfOWL, the BIM Collaboration Format Ontology.

- `https://w3id.org/bcfOWL#` is the namespace of the ontology.
- `https://w3id.org/bcfOWL` redirects to
  <https://design-computation-rwth.github.io/bcfOWL/>. A request with an
  `Accept` header for Turtle, JSON-LD, RDF/XML or N-Triples is redirected to
  that serialization.
- `https://w3id.org/bcfOWL/<version>`, for example
  `https://w3id.org/bcfOWL/1.0.0`, is the version IRI of a release. It
  redirects to the fixed copy of that release at
  `https://design-computation-rwth.github.io/bcfOWL/<version>/`, with the
  same content negotiation.

Repository: <https://github.com/Design-Computation-RWTH/bcfOWL>
