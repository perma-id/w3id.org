# /dredto/

Permanent identifier for DREDTO, the Ontology of cyberdiseases - diseases
resulting from exposure to digital technologies, developed by ITPCC.

The ontology IRI is `https://w3id.org/dredto`, and its terms are hash IRIs of
the form `https://w3id.org/dredto#SomeTerm`.

The identifier redirects (303) as follows:

- Requests with `Accept: application/owl+xml` go to the OWL/XML file:
  <https://www.itpcc.pl/research/cyberdiseases-ontology/dredto.owx>
- All other requests go to the BioPortal page:
  <https://bioportal.bioontology.org/ontologies/DREDTO>
