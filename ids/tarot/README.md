# Tarot ontology

Persistent identifiers for the tarot ontology and accompanying vocabularies.

- <https://w3id.org/tarot/ontology> — The ontology itself
- <https://w3id.org/tarot/symbol> — Symbology vocabulary
- <https://w3id.org/tarot/correspondence> - Correspondences vocabulary

And three example datasets.

- <https://w3id.org/tarot/deck/marseille> - rws deck
- <https://w3id.org/tarot/deck/marseille> - marseille deck
- <https://w3id.org/tarot/deck/sola-busca> - sola-busca deck
