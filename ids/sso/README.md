# SSO Ontology — https://w3id.org/sso

**Permanent URL:** `https://w3id.org/sso#` — the trailing `#` is used when minting ontology term URIs (e.g. `https://w3id.org/sso#StructuralAnalysisModel`).

## About

The Structural Simulation Ontology (SSO) provides an RDF/OWL representation of the structural analysis domain for integration into knowledge graph–based digital twins of buildings and infrastructure.

### Abstract

SSO represents structural simulation models and their relationships with built-environment entities, enabling structural analysis information to be queried, linked, and integrated with other domains within knowledge graphs. The ontology represents the main concepts of structural analysis, including objects, meshes, elements, sections, materials, boundary conditions, load cases, loads, and calibration information. SSO can also link structural simulation data to physical assets, provenance information, and external repositories containing complete simulation representations.
