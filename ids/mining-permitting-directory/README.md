# Mining Permitting Directory

Permanent identifier for a structured record of which authorizations a mining project requires, in
which jurisdiction, and on what documentary evidence. The `.htaccess` here redirects
`https://w3id.org/mining-permitting-directory/` and every path beneath it, with a `303 See Other`,
to documentation at the target below.

**Maintainer:** GitHub `SCPerm727` — <https://github.com/SCPerm727>. Scope is this redirect only:
the target has moved, the rule has stopped resolving, the path needs transferring or retiring.

**Target:** <https://scperm727.github.io/mining-permitting-directory/>, path suffix preserved. The
target is changeable by design; the `w3id.org` path is the permanent half. Content negotiation is
deliberately disabled until `ontology.ttl` and `ontology.rdf` resolve there.

**Status:** in development. The assessment lattice is structurally complete and legally unverified.
No Qualified Person has signed off on any of it, and nothing at the target should be relied on for
legal, regulatory, permitting or investment purposes. Detail is on the site.
