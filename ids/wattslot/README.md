# WattSlot

Permanent identifiers of [WattSlot](https://github.com/jmcruvellier/wattslot), a Home Assistant app that plans when to run household appliances around solar production and electricity prices.

- `https://w3id.org/wattslot/ontology#…`: classes and properties of the WattSlot ontology.
- `https://w3id.org/wattslot/ontology/library/home-energy`: "Home energy" library ontology.
- `https://w3id.org/wattslot/ontology/schema`: application schema ontology.
- `https://w3id.org/wattslot/home/…`: individuals of a user's home, local to each installation; redirected to the documentation.

RDF clients asking for Turtle get the files of [`docs/ontology/`](https://github.com/jmcruvellier/wattslot/tree/main/docs/ontology); browsers get the documentation page.
