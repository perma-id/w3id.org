# /olympic-lod/

Permanent identifiers for Olympic LOD: the Tokyo 2020 Olympic Games as 5-star Linked Open Data.

- `https://w3id.org/olympic-lod/ontology#…`: the ontology
- `https://w3id.org/olympic-lod/shapes#…`: the SHACL application profile
- `https://w3id.org/olympic-lod/scheme/{list}/{value}`: code lists
- `https://w3id.org/olympic-lod/tokyo2020/id/{type}/{key}`: the Tokyo 2020 data

Project: <https://github.com/danedyy/olympic-lod> · Dataset DOI: <https://doi.org/10.5281/zenodo.24543242>
