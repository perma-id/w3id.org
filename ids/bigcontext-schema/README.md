# /bigcontext-schema/

Permanent identifiers for BigContext Schema, an open standard (Apache 2.0) for recording business rules,
procedures, decisions and responsibilities, each tied to the source text it came from.

- `https://w3id.org/bigcontext-schema/` redirects to the specification's home page, to the OWL ontology for
  `Accept: text/turtle`, and to the JSON-LD context for `Accept: application/ld+json`.
- Each term, such as `https://w3id.org/bigcontext-schema/Rule`, redirects to the home page, or to the OWL ontology
  for `Accept: text/turtle`.
- `https://w3id.org/bigcontext-schema/facts/` and each term under it redirect to the fact vocabulary's OWL ontology.

Documentation: <https://github.com/BigContext-OpenSource/bigcontext-schema>
