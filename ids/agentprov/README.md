# /agentprov/

Permanent identifiers for AgentPROV, an execution-provenance framework for LLM-agent security research
(successor of AgentDojo-PROV), and for its vocabulary `apv:`.

- `https://w3id.org/agentprov/ns#`: vocabulary namespace. It redirects to
  <https://nickjones39.github.io/agentprov-ns/ns/>, or to the Turtle document for `Accept: text/turtle`.
- `https://w3id.org/agentprov/ns/<x.y.z>` (for example `…/ns/0.1.0`): a released version of the vocabulary, with
  the same content negotiation (HTML page or Turtle).
- `https://w3id.org/agentprov/exec/…`: execution instance IRIs. These are identifiers; they redirect to
  an explanation page.

Documentation: <https://nickjones39.github.io/agentprov-ns/>
