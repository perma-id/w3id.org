# /participate/

Permanent identifiers for the Participate protocol vocabulary, the JSON-LD
terms a Participate server uses in the ActivityPub ticket documents it
publishes.

`https://w3id.org/participate/ns` and `https://w3id.org/participate/` redirect
to the JSON-LD context at <https://pulzyn.github.io/participate-ns/ns.jsonld>.
Term IRIs are `https://w3id.org/participate/ns#<term>`, for example
`https://w3id.org/participate/ns#status`.

Documentation: <https://github.com/pulzyn/participate-ns>
