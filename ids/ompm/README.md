# /ompm/

Permanent identifiers for OMPM (ontology-mediated portable memory), starting
with the Memory Core ontology, `@mem/core`.

| IRI | Redirects to |
| --- | --- |
| `https://w3id.org/ompm/mem` (namespace `https://w3id.org/ompm/mem#`) | Latest release: Turtle for `Accept: text/turtle`, the package page otherwise |
| `https://w3id.org/ompm/mem.ttl` | Latest release, Turtle |
| `https://w3id.org/ompm/mem/<version>` | That release: Turtle for `Accept: text/turtle`, the package page otherwise |
| `https://w3id.org/ompm/mem/<version>.ttl` | That release, Turtle |
| `https://w3id.org/ompm/` | The package page |

Package page: <https://onto.melx.buzz/package/@mem/core>
