# U-CORE_Categories_Sensitivity

Permanent identifiers for the U-CORE sensitivity categories for war testimonies from Ukraine,
a SKOS vocabulary developed at the Luxembourg Centre for Contemporary and Digital History (C2DH),
University of Luxembourg.

https://w3id.org/U-CORE_Categories_Sensitivity redirects to the vocabulary file hosted on GitLab:
https://gitlab.com/uniluxembourg/c2dh/u-core/3.3-u-core-database-structure
