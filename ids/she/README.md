# she

`she` stands for **soil health europe**. This namespace provides persistent
identifiers for the Soil Health Knowledge Graph (SHKG).

- Persistent base IRI: [https://w3id.org/she](https://w3id.org/she)
- Intended RDF namespace IRI: [https://w3id.org/she#](https://w3id.org/she#)
- Project repository: [soilwise-he/soil-health-knowledge-graph](https://github.com/soilwise-he/soil-health-knowledge-graph)

## Redirects

The identifier root, with or without a trailing slash, uses HTTP 303 redirects:

- HTML and default requests: [WIDOCO documentation](https://soilwise-he.github.io/soil-health-knowledge-graph/).
- Requests accepting `text/turtle` or `application/x-turtle`: [complete SHKG Turtle file](https://soilwise-he.github.io/soil-health-knowledge-graph/soil_health_SKOS.ttl).

The content remains hosted on GitHub Pages; w3id provides the persistent redirects.
