# SmallData ML metadata schema (CRC 1597)

Persistent identifiers of the SmallData ML metadata schema, an application
profile for describing the machine learning approaches reported in scientific
publications, developed within the Collaborative Research Center 1597
"Small Data" at the University of Freiburg, Germany.

- Namespace: https://w3id.org/smalldata-ml/
- Concept scheme: https://w3id.org/smalldata-ml/scheme
- Items: https://w3id.org/smalldata-ml/SD-ML-nnn
- Record of the schema: https://doi.org/10.60493/gt98n-09n12

Requests with `Accept: text/turtle` are redirected to the SKOS serialization
of the schema; all other requests are redirected to the record of the schema
in FreiData, the research data repository of the University of Freiburg.
