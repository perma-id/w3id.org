# Eclipse Conformity Assessment Profile

## Homepage

The [Eclipse Conformity Assessment Profile (CAP)](https://pages.eclipse.dev/eclipse/dataspace-cap/cap-ontology/v0/) is an ontology, reference implementation and testbed (TCK) to express in RDF the information from [ISO/IEC 17000:2020 Conformity assessment — Vocabulary and general principles](https://www.iso.org/standard/73029.html) processes.
