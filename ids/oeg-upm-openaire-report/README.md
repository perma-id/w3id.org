# /oeg-upm-openaire-report/

Permanent identifier for the OpenAIRE Software Metadata Status Report, produced
by the Ontology Engineering Group (OEG) at Universidad Politecnica de Madrid: an
analysis of how research communities describe, manage and share software
metadata in code repositories, organised around five research questions.

`https://w3id.org/oeg-upm-openaire-report/` redirects to
<https://anas-elhounsri.github.io/openaire-report/>, which forwards to the
current version of the report.
