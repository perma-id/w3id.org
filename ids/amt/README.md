## Academic Meta Tool (AMT)

Repository created to store the redirections for the Academic Meta Tool: the vocabulary (with content negotiation), the Explorer, the data model page and the software repositories. The pages are hosted on GitHub Pages of the NFDI4Objects organisation (n4o-rse). The namespace of the vocabulary itself is http://academic-meta-tool.xyz/vocab# and does not change.
