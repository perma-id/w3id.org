# CRM-SDM W3ID Persistent Identifier

This directory provides persistent URL redirection (`https://w3id.org/crm-sdm`) for **CRM-SDM**: An OWL 2 Ontology for Firm-Level Stress Testing of Critical Raw Material Supply Chains.

## Documentation & Repository

The full documentation, ontology files, knowledge graph, and SHACL validation suite are hosted at:
* **Primary Repository:** [https://github.com/ndrberna/crm-sdm](https://github.com/ndrberna/crm-sdm)
