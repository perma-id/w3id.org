# GHGA

Persistent identifiers (`https://w3id.org/GHGA/...`) for the metadata schema of the
[German Human Genome-Phenome Archive (GHGA)](https://www.ghga.de/).

## Redirect target

All identifiers are redirected to the generated schema documentation (Markdown files in `docs/schema_markdown/`):

* `https://w3id.org/GHGA/`          -> https://github.com/ghga-de/ghga-metadata-schema/blob/main/docs/schema_markdown/index.md
* `https://w3id.org/GHGA/<Term>`    -> https://github.com/ghga-de/ghga-metadata-schema/blob/main/docs/schema_markdown/<Term>.md
