# molinology

Permanent identifiers for concepts in the **TIMS Dictionary of Molinology**
(The International Molinological Society), a multilingual thesaurus of
milling/windmill/watermill terminology.

`https://w3id.org/molinology/<id>` redirects to the concept's live page,
e.g. `https://w3id.org/molinology/4022` → the "rosmolen" (horse mill)
concept. Appending `?format=jsonld` or `?format=turtle` passes through to
the machine-readable representation.

Currently redirects to a pilot deployment at `millthesaurus.org`; will move
to a TIMS-owned domain once that is set up. The redirect is intentionally
a 302, so it can be repointed later without breaking any existing links
into `w3id.org/molinology/...`.
