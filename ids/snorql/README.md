# /snorql/

Permanent identifiers for [Snorql-UI](https://github.com/wikipathways/Snorql-UI), the SPARQL
query editor of the WikiPathways SPARQL endpoint, and for the format of the SPARQL example files
it reads.

- `https://w3id.org/snorql/ns` redirects to the vocabulary for SPARQL example files: Turtle for
  RDF clients, otherwise its documentation. `https://w3id.org/snorql/ns.ttl` always gives the
  Turtle file.
- `https://w3id.org/snorql/param` is the namespace for example parameter names and redirects to
  the same documentation.
- `https://w3id.org/snorql/` redirects to the Snorql-UI repository.

Documentation: <https://github.com/wikipathways/Snorql-UI/blob/master/tools/examples/README.md>
