# Cartograph Provenance

Permanent identifier for the Cartograph Provenance ontology, a PROV-O extension
that records how a map image was rendered (configuration, rendering activity,
style rules).

| URI | Redirects to |
|---|---|
| `https://w3id.org/cartograph-provenance` | `https://renedorsch.solidcommunity.net/apps/cartograph/cartograph-provenance.ttl` |

Terms use the hash namespace `https://w3id.org/cartograph-provenance#`.

Related: [`cartograph`](../cartograph).
