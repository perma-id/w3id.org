# aiprov

Permanent identifiers for **aiprov**, a domain-agnostic AI-provenance extension to
[W3C PROV-O](https://www.w3.org/TR/prov-o/): who (human, AI model, tool) did what to an artefact,
with inference telemetry and a verification ladder whose top rungs only humans may grant.
Generalised from F(AI)²R (arXiv:2607.25637).

| Identifier | Resolves to |
|---|---|
| `https://w3id.org/aiprov/` | project repository |
| `https://w3id.org/aiprov/ns` | current namespace document (Turtle for RDF clients, README otherwise) |
| `https://w3id.org/aiprov/ns/0.1` | the 0.1 namespace document, pinned to tag `v0.1.0` |
| `https://w3id.org/aiprov/ns#<Term>` | a term in the current namespace |

Namespace prefix: `aiprov: <https://w3id.org/aiprov/ns#>`
