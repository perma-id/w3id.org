# w3id.org/indivisual

## Purpose
This namespace provides persistent, "living" URLs for the data, code, and research materials associated with publications from the Indivisual Lab. 

Because our previous repository (OSF) has transitioned to a permanent read-only state, these w3id links ensure that URLs printed in our published papers continue to resolve to active, updatable archives. We primarily use this to redirect traffic to Zenodo Concept DOIs for our MRI, eye-tracking, and psychophysics datasets.
