# w3id.org/gil-next

Permanent identifiers for GIL (Raiden / Canon). Each GIL Atom has one opaque, version-free IRI
`https://w3id.org/gil-next/atom/{uuid-v4}`; it redirects (303) to its description at the gateway
https://tevintay249-stack.github.io/gil-next-id/ — HTML by default, Turtle on request.

Maintainer: Tevin Taylor — GitHub [@tevintay249-stack](https://github.com/tevintay249-stack)
