# /xenosite/

Permanent identifier namespace for [XenoSite](https://xenosite.org/), a research project developing computational methods for xenobiotic metabolism and chemical reactivity.

## Purpose and status

We plan to use `https://w3id.org/xenosite/` as an IRI namespace for XenoSite resources. This IRI use is still in development and has not yet been implemented.

For now, the namespace root and all paths beneath it redirect to https://xenosite.org/ using HTTP 302. This is an interim landing-page redirect; resource-specific resolution and any content negotiation will be added in a future update when implemented. Path suffixes are not forwarded.

## Project background

XenoSite is an established research project from the Swamidass laboratory at Washington University in St. Louis. Publications documenting the project include:

- Zaretzki, Matlock, and Swamidass (2013). *XenoSite: Accurately Predicting CYP-Mediated Sites of Metabolism with Neural Networks*. https://doi.org/10.1021/ci400518g
- Matlock, Hughes, and Swamidass (2015). *XenoSite server: a web-available site of metabolism prediction tool*. https://doi.org/10.1093/bioinformatics/btu761
- Hughes, Dang, Miller, and Swamidass (2016). *Modeling Reactivity to Biological Macromolecules with a Deep Multitask Network*. https://doi.org/10.1021/acscentsci.6b00162
- Dang, Matlock, Hughes, and Swamidass (2020). *The Metabolic Rainbow: Deep Learning Phase I Metabolism in Five Colors*. https://doi.org/10.1021/acs.jcim.9b00836
