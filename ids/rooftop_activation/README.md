# Rooftop Activation Ontology

Persistent identifier for the Rooftop Activation Ontology, which describes how building rooftops can be activated, the owners and incentives involved, and the urban challenges they address.

## Redirects

| Request | Redirects to |
|---|---|
| `https://w3id.org/rooftop_activation` (browser) | HTML documentation on GitHub Pages |
| `https://w3id.org/rooftop_activation` with `Accept: text/turtle` | `ontology.ttl` |
| `https://w3id.org/rooftop_activation` with `Accept: application/rdf+xml` | `ontology.owl` |
| `https://w3id.org/rooftop_activation` with `Accept: application/ld+json` | `ontology.jsonld` |
| `https://w3id.org/rooftop_activation` with `Accept: application/n-triples` | `ontology.nt` |
| `https://w3id.org/rooftop_activation/X.Y.Z` | RDF/XML file of Git tag `vX.Y.Z` |
