# Agentic Ontology of Work (AOW)

Permanent identifiers for the Agentic Ontology of Work, an open ontology for enterprise work performed by AI agents, people, and systems.

* Namespace: `https://w3id.org/aow#`
* Ontology: `https://w3id.org/aow`
* Versioned ontology: `https://w3id.org/aow/2.0.0`
* JSON-LD context: `https://w3id.org/aow/context.jsonld`
* SHACL shapes: `https://w3id.org/aow/shapes`
* JSON Schemas: `https://w3id.org/aow/schemas/{name}`

Requests for `https://w3id.org/aow` are redirected by content negotiation: `text/turtle` to the Turtle file, `application/ld+json` to the JSON-LD file, and all other requests to the HTML reference page.
