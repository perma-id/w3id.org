# KM Energy

Persistent identifiers for the conceptual ontology of an analytical workflow supporting causal-cognitive analysis of energy-system optimization results.

Repository: https://github.com/avmiheev/km-energy

Ontology namespace: `https://w3id.org/km-energy/ontology#`

## Redirects

| Path | Target |
|---|---|
| `/km-energy/` | GitHub project repository |
| `/km-energy/ontology` | Ontology in Turtle |
| `/km-energy/ontology.ttl` | Ontology in Turtle |
| `/km-energy/ontology.owl` | Ontology in RDF/XML |
| `/km-energy/example` | Example instances in Turtle |

Ontology and example-document redirects use HTTP 303. The project root uses HTTP 302.
The ontology uses hash IRIs, for example `https://w3id.org/km-energy/ontology#AnalyticalFactor`.
The fragment is handled by the client; `/ontology` resolves to the Turtle document.
Example instances use `https://w3id.org/km-energy/example#`.
