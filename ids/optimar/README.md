## Name of the project:

OPTiMAR

---

## Description:
Ontology modeling structural elements, mooring systems, sensors, events, and failures in floating offshore wind platforms, including measurement data, involved actors, and semantic relationships between components.
Reuses SOSA/SSN for observations, PROV-O for event and data provenance, and QUDT for quantities and units.

Source repository: https://github.com/bisite/OPTIMAR-Ontology
