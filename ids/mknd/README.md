# /mknd/

This [W3ID](https://w3id.org) provides a persistent URI namespace for the Mekanoid Ontology (MKND), a cybersecurity ontology that extends MITRE D3FEND.

- Documentation: https://mknd-io.github.io/ontologies/
- Source: https://github.com/mknd-io/ontologies

Requests are redirected (303) to GitHub Pages with content negotiation: HTML for browsers, and Turtle, RDF/XML, JSON-LD or N-Triples according to the `Accept` header. Version IRIs (`/mknd/0.4.0/`) resolve to release snapshots.
