# Image Scale Metadata (ISM)

Permanent identifiers for Image Scale Metadata, an open format for carrying the
true scale of an image — millimetres per pixel, the pixel grid it applies to,
and how it was measured — inside the image file's own XMP metadata.

- Specification: https://image-scale-metadata.github.io/
- Repository: https://github.com/image-scale-metadata/image-scale-metadata.github.io
- XMP namespace: `https://w3id.org/ism/0.1/` (one namespace per version)

| Identifier | Redirects to |
|---|---|
| `https://w3id.org/ism/` | https://image-scale-metadata.github.io/ |
| `https://w3id.org/ism/0.1/` | https://image-scale-metadata.github.io/ |
| `https://w3id.org/ism/<path>` | https://image-scale-metadata.github.io/<path> |
