# w3id.org/laubmann-kg

Permanent identifiers for the **Laubmann Knowledge Graph** (HistOrniGraph): an RDF
knowledge graph and Darwin Core Archive built from the ornithological field
diaries of Alfred Louis Laubmann (Bavaria, 1917–1965, 34 volumes).

| IRI | resolves to |
|---|---|
| `https://w3id.org/laubmann-kg/ontology` (namespace `…/ontology#`, prefix `lkg`) | OWL ontology — Turtle for RDF clients, pyLODE documentation for browsers |
| `https://w3id.org/laubmann-kg/ontology/<x.y.z>` | versioned ontology (git tag `v<x.y.z>`; current `owl:versionIRI` is `…/ontology/0.7.1` → tag `v0.7.1`) |
| `https://w3id.org/laubmann-kg/vocabularies` | SKOS concept schemes (controlled values) |
| `https://w3id.org/laubmann-kg/shapes` | SHACL shapes |
| `https://w3id.org/laubmann-kg/context.jsonld` | JSON-LD context |
| `https://w3id.org/laubmann-kg/data/<id>` | instance IRIs (entries, observations, taxa, places, persons, runs); until a resolver exists they land on the data documentation page |

Source repository: https://github.com/desyLoyz/laubmann-kg
