# LiGre - Lemma Bank for Ancient Greek

Persistent identifiers for [LiGre](https://github.com/ligre-lod), a Linked Open
Data lemma bank for Ancient Greek modelled with OntoLex-Lemon and the
[LiLa](https://lila-erc.eu/) ontology, developed at Ghent University.

All requests under `https://w3id.org/ligre/` are redirected (303), with their
path preserved, to `https://ligre.ugent.be/`, e.g.

- `https://w3id.org/ligre/data/id/lemma/8` -> `https://ligre.ugent.be/data/id/lemma/8`
