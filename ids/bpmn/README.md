# BPMN 2.0 in RDF

Persistent identifiers for "BPMN 2.0 in RDF", a draft OWL ontology and SHACL
validation set for BPMN 2.0.2 (OMG). The ontology is generated from OMG's
machine-readable metamodel; the connection matrix and the normative rules of
the specification are published as data, with a bridge to ArchiMate 4.0.

This is not an OMG publication.

* Namespace: `https://w3id.org/bpmn#`
* Source and issue tracker: https://github.com/jwvveen/bpmn-rdf

RDF clients (`Accept: text/turtle`) are redirected to the Turtle files;
browsers to the repository.
