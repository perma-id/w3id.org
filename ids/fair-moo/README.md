# FAIR-MOO

## Permanent identifier namespace

https://w3id.org/fair-moo/

## Description

FAIR-MOO provides persistent semantic identifiers and definitions
for concepts used in FAIR Research Data Management of
Multi-Objective Optimisation experiments.

The namespace is intended to identify experiment-related concepts,
including optimisation objectives, problems, algorithms, performance
indicators, constraints, and related semantic entities for which an
appropriate external persistent identifier is not available.

Existing external identifiers are reused whenever suitable identifiers
already exist.
