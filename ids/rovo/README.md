# /rovo/

Permanent identifiers for R.O.V.O, the Remote Operation of Vehicles Ontology:
an ontology of the remote driving (road vehicle teleoperation) context,
covering the remote operator's situation awareness and the communication link
between the vehicle and the remote station.

- `https://w3id.org/rovo/{core,op,link,op-shapes,link-shapes}` are the
  ontology IRIs, with hash namespaces (e.g.
  `https://w3id.org/rovo/op#RemoteOperator`). RDF clients are redirected to
  the ontology file, everything else to the documentation page.
- `https://w3id.org/rovo/{module}.ttl` redirects to the Turtle file. For
  `core`, `op` and `link`, `.owl`, `.jsonld` and `.nt` redirect to the RDF/XML,
  JSON-LD and N-Triples files.
- `https://w3id.org/rovo/` redirects to <https://sanatmharolkar.github.io/ROVO/>.

Source: <https://github.com/sanatmharolkar/ROVO>
