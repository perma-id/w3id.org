# /rdonto/

Permanent identifiers for RDOnto, the Remote Driving Ontology: an ontology of
the remote driving (road vehicle teleoperation) context, covering the remote
operator's situation awareness and the communication link between the vehicle
and the remote station.

- `https://w3id.org/rdonto/{core,op,link,op-shapes,link-shapes}` are the
  ontology IRIs, with hash namespaces (e.g.
  `https://w3id.org/rdonto/op#RemoteOperator`). RDF clients are redirected to
  the Turtle file, everything else to the documentation page.
- `https://w3id.org/rdonto/{module}.ttl` redirects to the Turtle file.
- `https://w3id.org/rdonto/` redirects to <https://sanatmharolkar.github.io/RDOnto/>.

Source: <https://github.com/sanatmharolkar/RDOnto>
