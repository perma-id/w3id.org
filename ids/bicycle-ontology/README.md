# Bicycle Ontology

An example OWL ontology developed for the [TDCC-NES ontology training](https://github.com/TDCC-NES/ontology-training).

**Namespace:** `https://w3id.org/bicycle-ontology/`

The namespace uses HTTP 303 redirects to provide the [Turtle ontology](https://tdcc-nes.github.io/ontology-training/main/bicycle-ontology.ttl) or [HTML documentation](https://tdcc-nes.github.io/ontology-training/main/bicycle-ontology.html), depending on the HTTP `Accept` header.
