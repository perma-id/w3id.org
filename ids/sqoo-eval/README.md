# SQOO Persistent Identifiers

Persistent identifiers for Software Quality Observatory
Orchestrator (SQOO), a system for automated research software
cataloguing and quality assessment.

## Identifiers

- `/sqoo-eval/`: SQOO evaluation catalogs.
