# /epiphoto/

Permanent identifiers for Epiphoto, sourced records about photographers for
the critical reading of photography.

`https://w3id.org/epiphoto/` redirects to <https://epiphoto.org/>.

`https://w3id.org/epiphoto/<id>` redirects, with 303 See Other, to
`https://epiphoto.org/<id>`, the page about what the identifier names.
