# /agent-evidence/

Persistent identifiers for [Agent Evidence](https://github.com/probityai/agent-evidence): in-toto predicate types, conformance vectors and verifiers for evidence about the runs of AI agents.

| Identifier | Redirects to |
| --- | --- |
| `https://w3id.org/agent-evidence/` | https://probityai.github.io/agent-evidence/ |
| `https://w3id.org/agent-evidence/predicate/v1/` | https://probityai.github.io/agent-evidence/predicate/v1/ |
| `https://w3id.org/agent-evidence/predicate/v1/{name}` | `https://probityai.github.io/agent-evidence/predicate/v1/{name}/` |

A predicate type URI is written inside the statements producers sign, so these identifiers do not change; if the pages move, only the redirect targets here change.
