# /agent-evidence/

Persistent identifiers for [Agent Evidence](https://github.com/probityai/agent-evidence): in-toto predicate types, a term vocabulary, conformance vectors and verifiers for evidence about the runs of AI agents.

| Identifier | Redirects to |
| --- | --- |
| `https://w3id.org/agent-evidence/` | https://probityai.github.io/agent-evidence/ |
| `https://w3id.org/agent-evidence/predicate/v1/` | https://probityai.github.io/agent-evidence/predicate/v1/ |
| `https://w3id.org/agent-evidence/predicate/v1/{name}` | `https://probityai.github.io/agent-evidence/predicate/v1/{name}/` |
| `https://w3id.org/agent-evidence/vocab/v1/` | https://probityai.github.io/agent-evidence/vocab/v1/ |
| `https://w3id.org/agent-evidence/vocab/v1/{term}` | `https://probityai.github.io/agent-evidence/vocab/v1/{term}/` |
| `https://w3id.org/agent-evidence/vocab/v1/registry/sha256-{hex}.yaml` | `https://probityai.github.io/agent-evidence/vocab/v1/registry/sha256-{hex}.yaml` |

A predicate type URI or a term URI is written inside the records producers sign, so these identifiers do not change; if the pages move, only the redirect targets here change. A registered value of a term is the term URI with the value as its fragment.
