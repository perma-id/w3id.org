# MARCO-BOLO

Funded by the EU Horizon Europe programme (along with UKRI), MARCO-BOLO is a €7.3 million, 4-year project that will strengthen European marine, coastal and freshwater biodiversity observation to understand and restore ocean health.

The permanent identifiers (PIDs) held here are maintained by [Work Package 1 (WP1)](https://marcobolo-project.eu/work-packages/work-package-1-delivering-essential-biodiversity-variables-local-to-global-biodiversity-metadata-for-coastal-and-marine-systems/). Please make contact with a member of WP1 if you require a PID to be setup or its current location altered.

## Identifier resolution

Identifiers in this namespace take the form `mbo_<uuid>`, where `<uuid>` is a
lowercase RFC 4122 UUID, for example:

    https://w3id.org/marco-bolo/mbo_000a42bb-7b6b-4c23-a47b-f08e0ab253ae

Each resolves with a `303 See Other` to the JSON-LD document describing it,
served from:

    https://lab.marcobolo-project.eu/csv-to-json-ld/schema-jsonld/<identifier>.json

Those documents are generated by the
[csv-to-json-ld](https://github.com/marco-bolo/csv-to-json-ld) pipeline.

`303` is used rather than `302` because these identifiers denote real-world
things -- a person, a dataset, a sampling platform -- and not the documents
that describe them.

Each entity also carries a provenance description identified by the suffix
`-input-metadata`. That description is embedded in the entity document itself
under `subjectOf` rather than being a separate file, so those identifiers
resolve to the same document.

Three identifiers minted before the move to UUIDs — `mbo_0000001` to
`mbo_0000003`, for the grant, the European Union and the MARCO-BOLO project —
redirect with a `301 Moved Permanently` to the `mbo_<uuid>` identifiers which
superseded them. They denote the same three things and are now described by the
catalogue rather than by a frozen copy held elsewhere.
