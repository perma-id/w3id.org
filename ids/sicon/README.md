# https://w3id.org/sicon

**Project:** SICON — A Spatial Iconography Ontology Design Pattern

An ontology design pattern for representing the spatial configuration of visual
elements distributed across the surfaces of cultural heritage three-dimensional built structures
and objects. Aligned with CIDOC CRM.

The identifier resolves, via content negotiation, either to the HTML
documentation or to the ontology in Turtle, RDF/XML, JSON-LD or N-Triples.
A hash namespace is used (`https://w3id.org/sicon#Term`), so a single rule on
the base IRI is sufficient.
