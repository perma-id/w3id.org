# /bigcontext/

Permanent identifiers minted by BigContext's software.

- `https://w3id.org/bigcontext/context-warehouse/orgs/<org-id>/records/<record-id>/` names one record in a Context
  Warehouse: a message, or a document derived from one, stored for one organization. An element of the record is the
  record's identifier followed by the element's id, such as
  `https://w3id.org/bigcontext/context-warehouse/orgs/<org-id>/records/<record-id>/c.customer`. These identifiers
  appear as `base_iri` values in [BigContext Schema](https://w3id.org/bigcontext-schema/) documents.
- A record is readable only through its organization's Context Warehouse, with that organization's key. Every
  request for an identifier in this space redirects to this page.
