# Skeleton Ontology

The Skeleton ontology supplies the structural backbone for representing experimental and manufacturing procedures as knowledge graphs. It is intentionally minimal: it draws on the essential classes of [EMMO](https://w3id.org/emmo/) and its domain modules, and introduces new terms namely for process parameters and for the planning of procedures and objects.
