# /fair-map/

Permanent identifiers for the FAIR Mappings Schema, a LinkML schema for
describing FAIR mapping specifications, developed by the RDA FAIR Mappings
Working Group.

`https://w3id.org/fair-map/` redirects to <https://mapping-commons.github.io/fair-mappings-schema/>.

- `https://w3id.org/fair-map/schema` is the schema id and resolves to the schema
  documentation.
- `https://w3id.org/fair-map/fair-map.yaml` and `https://w3id.org/fair-map/schema.yaml`
  resolve to the LinkML schema source.
- `https://w3id.org/fair-map/<Element>` resolves to the documentation page of that
  schema class, slot or enum.
