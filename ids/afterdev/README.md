# /afterdev/

Permanent identifiers for AfterDev - 현상후, a free app for organizing film scans.

`https://w3id.org/afterdev/` redirects to <https://afterdevfilm.github.io/>.

The XMP namespace `https://w3id.org/afterdev/xmp/1.0/` is described at <https://afterdevfilm.github.io/xmp/1.0/>.
