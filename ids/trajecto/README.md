# Trajecto ontology

Permanent identifiers for the Trajecto ontology, a modular OWL ontology for semantic trajectories:
GPS-derived movement of people, the points of interest they interact with, movement patterns,
purposes, context, and user profiles.

- `https://w3id.org/trajecto`: core module, imports every module
- `https://w3id.org/trajecto/<module>`: modules `poi`, `spaces`, `purpose`, `purpose/skos`, `context`,
  `patterns`, `spatial`, `temporal-dwell`, `events`, `scheduled`, `profiles`, `user`

Browsers are redirected to the documentation at https://sotirisang.github.io/trajecto-stakg/;
RDF clients receive RDF/XML, Turtle, JSON-LD or N-Triples by content negotiation.

Source: https://github.com/sotirisAng/trajecto-stakg
