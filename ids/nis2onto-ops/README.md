# NIS2Onto-ops

NIS2Onto-ops is an operational ontology that extends [NIS2Onto](https://github.com/gianpietroc/nis-ontology) with the concepts needed to monitor assets, track security events, and record cybersecurity evidence
in the context of NIS2 Article 21 risk-management obligations. It adds a compliance-governance layer that ties control judgements back to specific regulatory requirements, 
enabling automated, evidence-based classification of compliance status over time. Developed as part of the NIS2Graph project.
