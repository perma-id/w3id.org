# NLTL

Permanent identifiers for the Natural-Language-to-Logic (NLTL) project.

NLTL is a research project developed at Aalto University for translating
natural-language engineering and maritime regulatory requirements into
machine-readable semantic constraints, including SHACL.

https://w3id.org/nltl/
