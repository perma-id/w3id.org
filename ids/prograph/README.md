# prograph: ProGraph vocabularies

Permanent identifiers for ProGraph, a virtual graph layer that runs SPARQL and Cypher over
tabular data. Source: https://gitlab.com/briceg/prograph

- `https://w3id.org/prograph/` and every path under it redirect to the same path on
  https://prograph.app/, for example `https://w3id.org/prograph/endpoint#rowCap`.
