# AIDOC-AP - AI Documentation Application Profile

The AI Documentation Application Profile (AIDOC-AP) is an ontology designed to provide a structured, machine-readable documentation of an AI system and its lifecycle.

Author/Maintainer: Sebastian Neumaier (sebastian.neumaier@ustp.at) @sebneu

Co-authors: Fabian Kovac, Timea Pahi, Tobias Dam

Organisation: University of Applied Sciences St. Pölten, Austria

AIDOC-AP documentation is online at https://certain-project.github.io/aidoc-ap/

The AIDOC-AP Lifecycle Extension (https://w3id.org/aidoc-ap/lifecycle, namespace https://w3id.org/aidoc-ap/lifecycle#) is documented at https://certain-project.github.io/aidoc-ap-lifecycle/

The AIDOC-AP LEX Extension (https://w3id.org/aidoc-ap/lex, namespace https://w3id.org/aidoc-ap/lex#, requirements https://w3id.org/aidoc-ap/lex/requirements#) is documented at https://certain-project.github.io/aidoc-ap-lex/
