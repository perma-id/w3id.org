# /em/

Legacy alias of [/extendedmatrix/](../extendedmatrix/) (perma-id/w3id.org#6722),
same maintainer.

Before `/extendedmatrix/` was registered, the Extended Matrix tools published
IRIs under `/em/`: the ontology namespace `https://w3id.org/em/ontology#` and the
node IRIs of exported RDF. Those IRIs are in data already published, so every
path under `/em/` is permanently redirected (301) to the same path under
`/extendedmatrix/`. No new content is served here.
