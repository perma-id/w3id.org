# Knowledge Graphs at DTAI division of KU Leuven

This [w3id](https://w3id.org/dtai-kg) provides a persistent URI namespace for work related to the Knowledge Graphs at DTAI division of KU Leuven.

## Uses

| w3id    | Description                        | URL                               |
| ------- | ---------------------------------- | --------------------------------- |
| /       | Main entry point of DTAI resources | https://github.com/dtai-kg        |
| /tactic | The TACTIC project landing page    | https://dtai-kg.github.io/TACTIC/ |
