# Florilegium

Florilegium is a reading workspace that keeps annotations and decisions as W3C Web Annotation records in JSON-LD.
This identifier holds the vocabulary those records use.

## Persistent URIs

- `https://w3id.org/florilegium/ns#` is the namespace of the vocabulary's terms.
- `https://w3id.org/florilegium/ns/v1.jsonld` is version 1 of its JSON-LD context.

Everything under `https://w3id.org/florilegium/` redirects to `https://jt-halbert.github.io/florilegium-ns/`,
published from <https://github.com/jt-halbert/florilegium-ns>.
