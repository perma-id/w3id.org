# OPINO

Persistent identifiers for **OPINO - OPinions and INterpretations Ontology**, a DOLCE+DnS Ultralite based ontology design pattern for scholarly opinions and interpretations in cultural heritage knowledge graphs, developed in the INFINITY project (Horizon Europe, grant agreement no. 101233051).

- `http://w3id.org/opino/` is the ontology, `http://w3id.org/opino/0.2.0` its version IRI, and `http://w3id.org/opino/<Term>` its terms.

Requests are redirected (303) to the files in https://codeberg.org/infinity-project/opino with content negotiation (Turtle, RDF/XML, JSON-LD, N-Triples), and to the HTML documentation at https://infinity-project.codeberg.page/opino/ for browsers.
