# RevMeta namespace (`https://w3id.org/revmeta/`)

RevMeta provides persistent identifiers for concepts, facets, coding guidance and related metadata used to describe research review publications. The public documentation and RDF representations are hosted at:

- https://mmarcinmichal.github.io/revmeta/
- https://mmarcinmichal.github.io/revmeta/vocabulary.ttl
- https://mmarcinmichal.github.io/revmeta/vocabulary.jsonld

This W3ID directory redirects requests to the appropriate representations; it does not maintain a registry of approved concept names. A path matching a redirect pattern does not prove that the corresponding concept or guidance item exists. The published RDF determines which identifiers are defined.
