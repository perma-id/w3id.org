# GATE Data Spaces (GDS)

GATE Data Spaces (GDS) develops semantic resources, including ontologies, vocabularies, and profiles, to support semantic interoperability and policy representation in data space environments. This [w3id](https://w3id.org/) provides a persistent URI namespace for GDS resources developed by the GATE Institute, Sofia University, and hosted on GitHub at [https://github.com/gate-institute/gateds-ontologies](https://github.com/gate-institute/gateds-ontologies). The w3id paths are mapped to the corresponding published resources through the `.htaccess` file.
