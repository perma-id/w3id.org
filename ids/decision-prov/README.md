# decision-prov

`https://w3id.org/decision-prov` identifies a vocabulary (prefix `dprov:`) for reading the records of the Decision
Provenance Standard as W3C PROV: one reader's reading, not part of that Standard. The identifier redirects to the
vocabulary's description in its repository, and `https://w3id.org/decision-prov/context.jsonld` to its JSON-LD context.

Maintainer: Laurent Lemonnier (GitHub: Laurent-Lemonnier).
