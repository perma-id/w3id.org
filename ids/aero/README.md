## 1. Purpose

This namespace provides permanent, resolvable identifiers (PURLs) for ontologies,
vocabularies and controlled terminologies of the **European Aerospace Domain**.

The namespace is organised in multiple layers:

| Layer | Prefix | Scope |
|---|---|---|
| Top-level domain ontology | `https://w3id.org/aero/core/` | Shared upper concepts, cross-cutting classes, properties and reference individuals valid for the whole aerospace domain |
| Domain ontologies | `https://w3id.org/aero/domain/` | Specialised modules per subdomain, importing and extending `aero/core` |
