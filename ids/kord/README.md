# KORD: Automatic Construction of Linked, Provenance-Aware Knowledge for Relational Databases

Permanent identifiers for the KORD bundles and their publication vocabulary.

- Vocabulary: `https://w3id.org/kord/vocab/`
- Catalog of all bundles (DCAT): `https://w3id.org/kord/bundle/`
- Bundles: `https://w3id.org/kord/bundle/<split>/<database>/…`
- Profile (JSON-LD context, vocabulary, SHACL shapes): `https://w3id.org/kord/bundle/profiles/kord/`

Code and documentation: https://github.com/wagner-niklas/kord
