# /federated-ads/

Persistent identifiers for the [Federated Ads Protocol](https://github.com/federated-ads/spec), an open protocol for federated advertising (discussion draft).

| Identifier | Redirects to |
|---|---|
| `https://w3id.org/federated-ads/v0` | JSON-LD context (for `application/ld+json` or `application/json`), otherwise the vocabulary page |
| `https://w3id.org/federated-ads/errors/<name>` | Error type documentation |
| `https://w3id.org/federated-ads/rel/<name>` | Link relation documentation |
| `https://w3id.org/federated-ads/tax/...` | Content taxonomy (planned) |
| anything else | Project site, https://federated-ads.github.io/spec/ |
