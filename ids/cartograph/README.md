# Cartograph

Permanent identifiers for the Cartograph ontology, a vocabulary for describing
rendered map images: display elements, visible objects, portrayals and their
pixel-space geometry.

| URI | Redirects to |
|---|---|
| `https://w3id.org/cartograph` | `https://renedorsch.solidcommunity.net/apps/cartograph/cartograph.ttl` |
| `https://w3id.org/cartograph/shapes` | `https://renedorsch.solidcommunity.net/apps/cartograph/cartograph-shapes.ttl` |

Terms use the hash namespace `https://w3id.org/cartograph#`.

Related: [`cartograph-provenance`](../cartograph-provenance).
