# /owp/

Persistent identifiers for the [Open World Package](https://github.com/ontle-world/open-world-package) (OWP) specification.

| Identifier | Redirects to |
|---|---|
| `https://w3id.org/owp/ns#` | the OWP vocabulary: Turtle, JSON-LD, or HTML by `Accept` (303) |
| `https://w3id.org/owp/ns/{release}` | a release of the vocabulary |
| `https://w3id.org/owp/align/{prov,bfo,dul}` | informative alignments to PROV-O, BFO 2020 + IAO, DOLCE+DnS Ultralite |
| `https://w3id.org/owp/spec/{apiVersion}` | a specification snapshot |
| `https://w3id.org/owp/pkg/{namespace}/{name}/{version}` | a page about the package identifier |

Content is served by GitHub Pages of `ontle-world/open-world-package`.
