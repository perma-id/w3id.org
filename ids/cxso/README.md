# /cxso/

Permanent identifiers for the Cathexis Somatic Ontology (CSO), an open, machine-readable vocabulary for somatic experience.

`https://w3id.org/cxso/` redirects to <https://cathexis-health.github.io/cxso/>.

- Ontology: `https://w3id.org/cxso`
- Terms: `https://w3id.org/cxso/CXSO_0000001` onward
- Releases: `https://w3id.org/cxso/releases/2.0.0/cxso.ttl`

Source and documentation: <https://github.com/cathexis-health/cxso>
