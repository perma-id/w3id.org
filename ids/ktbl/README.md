# /ktbl/

Permanent identifiers of KTBL (Kuratorium für Technik und Bauwesen in der
Landwirtschaft e.V.).

## Identifiers

- `https://w3id.org/ktbl/id/crop/` – InVeKoS / IACS Germany crop code
  vocabulary (SKOS), redirects to
  <https://agroportal.eu/ontologies/IACS>
- `https://w3id.org/ktbl/id/crop/{id}` – single concepts, e.g.
  `https://w3id.org/ktbl/id/crop/iacs-de-115`, redirect to
  `https://agroportal.eu/ontologies/IACS/{id}`

All redirects use HTTP 303. AgroPortal returns HTML or RDF depending on the
`Accept` header.
