# pathology-wsi

Top-level namespace for whole-slide imaging (WSI) repositories from 
pathology research projects. Sub-identifiers under this namespace point 
to individual project repositories.

Current sub-identifiers:
- `alk-thyroid` — ALK-rearranged follicular thyroid neoplasm cohort 
  (Mass General Brigham and Lenox Hill Hospital)
