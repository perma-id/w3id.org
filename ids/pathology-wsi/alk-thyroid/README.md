# pathology-wsi/alk-thyroid

Permanent redirect to a whole-slide imaging (WSI) repository for a 
multi-institutional cohort of ALK-rearranged follicular thyroid neoplasms.

Cases are drawn from Mass General Brigham and Lenox Hill Hospital 
(Northwell Health). The repository is publicly accessible and provides 
high-resolution, interactive WSI for review. Additional cohort cases may 
be added over time as they become available for digitization.

This identifier accompanies a manuscript currently in preparation/under 
review.
