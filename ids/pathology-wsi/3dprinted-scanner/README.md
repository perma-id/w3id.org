# pathology-wsi/3dprinted-scanner

Namespace for projects and viewers associated with an open-source,
3D-printed whole-slide scanner.

Current sub-identifiers:
- `commercial-comparison`: viewer for comparing scans from the
  3D-printed scanner against a commercial instrument
