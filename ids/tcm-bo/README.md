# TCM-BO — Traditional Chinese Medicine Body-structure Ontology

Persistent identifiers for **TCM-BO**, a bilingual (Chinese–English) OWL 2 DL ontology of traditional Chinese medicine body structures, aligned with ICD-11, FMA and SNOMED CT.

- Ontology IRI: http://OntoTCM.org.cn/ontologies/TCM_TO
- Current release: 1.9.17 (2026-09-03), strict OWL 2 DL, zero profile violations
- Source repository: https://github.com/Pinellia7ternata/TCM-BO
- Archive DOI: https://doi.org/10.5281/zenodo.22638644
