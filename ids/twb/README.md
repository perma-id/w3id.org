# TWB — Thin-Walled Blueprint

An OWL ontology of a building described as zero-thickness surfaces on the reference planes of its
walls, floors and roofs, with construction knowledge (recipes, joint details, requirements)
attached where it belongs. It is the data model of [arch](https://github.com/MadsHolten/arch).

## Redirects

| w3id | Target |
| --- | --- |
| `https://w3id.org/twb` | Browser: `https://twb.madsholten.dk/en/datamodel/`; otherwise `https://twb.madsholten.dk/ontology/twb.ttl` — the ontology |
| `https://w3id.org/twb/{shapes,doc,align}` | The same way, to `https://twb.madsholten.dk/ontology/twb-{shapes,doc,align}.ttl` — SHACL shapes, documentation module, alignments |
| `https://w3id.org/twb/catalogue/arch` | The same way, to `https://twb.madsholten.dk/ontology/twb-catalogue.ttl` — arch's catalogue as SKOS |
| `https://w3id.org/twb/{name}.ttl` | Always the Turtle of that module |
| `https://w3id.org/twb/context/{n}.jsonld` | `https://twb.madsholten.dk/context/{n}.jsonld` — the JSON-LD context of the house file, version `n` |
