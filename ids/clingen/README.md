# ClinGen

This [W3ID](https://w3id.org) provides a persistent URI namespace for JSON Schemas and
related assets maintained by the Clinical Genome Resource (ClinGen) in the
[clingen-data-model](https://github.com/clingen-data-model) GitHub organization
(e.g. the ClinVar-GKM schema set: VRS / Cat-VRS / VA-Spec representations of ClinVar).
