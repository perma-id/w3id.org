# PADC

Paris Astronomical Data Center (PADC).
[Project Website](https://padc.obspm.fr)

### About Paris Astronomical Data Centre

The Paris Astronomical Data Centre aims at providing interoperable access to its database resources, at 
participating to international standards developments, at implementing interoperable simulation codes, 
data visualization and analysis software. It participates to the three main astronomy data alliance: the 
[International Virtual Observatory Alliance](https://ivoa.net), the [International Heliophysics Data 
Environment Alliance](https://ihdea.net) and the [International Planetary Data 
Alliance](https://planetarydata.org).

PADC hosts high level permanent activities for tools and data distribution under the format of reference 
services. These sustainable services are recognized at the national level as CNRS labeled services.

Paris Astronomical Data Centre offers a central support to the various projects through central storage 
and web servers computing facilities. PADC provides training through tutorials and seminars in various areas, 
such as images, spectra and numerical simulations.
