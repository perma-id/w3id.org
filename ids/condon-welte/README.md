# condon-welte

The red Welte rolls of the Condon collection at Stanford Libraries, as linked data in the
format of linked-rolls: premises for dating a roll, each a belief with the evidence it rests
on, the classes of paper the premises name, and the hands that signed the rolls, as
authority records for persons known by a signature rather than identified.
