# /dita2graph/

Permanent identifiers for the vocabulary of
[DITA2Graph](https://github.com/jyjeanne/DITA2Graph), which builds a
knowledge graph from DITA documentation.

| Identifier | Redirects to |
| --- | --- |
| `https://w3id.org/dita2graph/ns` | The d2g vocabulary (namespace `https://w3id.org/dita2graph/ns#`), latest release: Turtle for `Accept: text/turtle`, its documentation otherwise |
| `https://w3id.org/dita2graph/ns/<version>` | That release of the vocabulary |
| `https://w3id.org/dita2graph/shapes` | The SHACL shapes graph, latest release, negotiated the same way |
| `https://w3id.org/dita2graph/ns.ttl`, `https://w3id.org/dita2graph/shapes.ttl` | The Turtle files, whatever the `Accept` header |
| `https://w3id.org/dita2graph/` | The project repository |

The Turtle files are published on
<https://jyjeanne.github.io/DITA2Graph/> from the repository tags
`d2g-<version>`.

Documentation:
<https://github.com/jyjeanne/DITA2Graph/blob/main/docs/semantic-model.md>
