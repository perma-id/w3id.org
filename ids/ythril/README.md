# /ythril/

Permanent identifiers of the [Ythril](https://github.com/ythril-network/Ythril) project, an open-source knowledge graph server.

| Identifier | Redirects to |
|---|---|
| `https://w3id.org/ythril/` | The project: <https://github.com/ythril-network/Ythril> |
| `https://w3id.org/ythril/ns` (asked for `text/turtle`) | The Ythril vocabulary as Turtle: `docs/rdf/ythril.ttl` in the project's repository |
| `https://w3id.org/ythril/ns` (any other request) | The vocabulary's documentation page: `docs/rdf/ythril-vocabulary.md` in the project's repository |

`https://w3id.org/ythril/ns` is the namespace of the Ythril vocabulary: the terms Ythril's RDF export defines itself, written `https://w3id.org/ythril/ns#Term` (prefix `ythril:`).
