# /hco/

Permanent identifiers for the Heat pump Common Ontology (HCO), its SHACL shapes
and example data, developed in the TDI500 project.

- `https://w3id.org/hco/ontology` and `https://w3id.org/hco/ontology/<version>`:
  the ontology, with content negotiation (HTML, Turtle, RDF/XML, JSON-LD,
  N-Triples)
- `https://w3id.org/hco/shacl` and `https://w3id.org/hco/shacl/<version>`: the
  SHACL shapes (HTML, Turtle)
- `https://w3id.org/hco/data/<name>`: example data (Turtle)

Content is hosted at <https://tdi500.gitlab.io/heatpump-common-ontology/>.
Source and documentation: <https://gitlab.com/tdi500/heatpump-common-ontology>
