# oversight-vocab

Persistent identifiers for an open SKOS controlled vocabulary of District of Columbia government
agencies, oversight concepts, program areas, budget units, funds and findings types, used for entity
resolution and search across public oversight tools.

- Home: https://inplainsight-dc.github.io/oversight-vocab/
- Maintainer: philippa-mk on GitHub (issues: https://github.com/inplainsight-dc/oversight-vocab/issues)
- Redirect pattern: concept IRIs are `https://w3id.org/oversight-vocab/<scheme>/<code>` and are never
  versioned; frozen releases live under `https://w3id.org/oversight-vocab/releases/<version>/`.
