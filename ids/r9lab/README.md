# /r9lab/

Permanent identifiers for the R9lab reference vocabulary.

`https://w3id.org/r9lab/vocabulary/` holds its concept IRIs: SKOS concept schemes for product types and component and
material classes. Every URL under `https://w3id.org/r9lab/` redirects to
<https://github.com/simonvanlierde/r9lab-vocabulary>.
