# OAKE – Ontology for the Astronomical Knowledge Ecosystem

This namespace provides persistent identifiers for OAKE, an ontology
designed to support semantic interoperability across professional
and amateur astronomy.

## Project

- GitHub: https://github.com/astrosemantics/oake
- Maintainer: Steven Piel (@spiel-ifremer)
- Organisation: AstroSemantics

## Persistent identifiers

- Ontology: https://w3id.org/astrosemantics/oake
- Ontology terms: https://w3id.org/astrosemantics/oake#<term>
- Versioned ontology: https://w3id.org/astrosemantics/oake/0.1.0

## Status

OAKE v0.1.0 is under development.

The namespace initially redirects to the project repository.
Versioned RDF distributions, content negotiation and semantic
documentation will be introduced as the ontology matures.
