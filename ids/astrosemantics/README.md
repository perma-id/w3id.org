# AstroSemantics – Astronomical Semantic Artefacts

This namespace provides persistent identifiers for semantic artefacts
related to astronomy, including ontologies, controlled vocabularies,
knowledge graphs and associated metadata.

AstroSemantics aims to support semantic interoperability between
professional and amateur astronomy communities.

## Scope

The namespace is designed to accommodate multiple independent
semantic artefacts.

Initial project:
- OAKE – Ontology for the Astronomical Knowledge Ecosystem

Additional artefacts may be registered in the future.
