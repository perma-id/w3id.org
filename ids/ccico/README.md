# w3id.org/ccico — 中文临床知情同意书应用本体（CCICO）

## 命名空间

- 持久 IRI：`https://w3id.org/ccico/`
- 本体 IRI：`https://w3id.org/ccico/ccico.owl`
- 版本 IRI：`https://w3id.org/ccico/releases/0.9.0-dev/ccico.owl`
- 实体子空间：`/md/`（医学概念）、`/to/`（文本操作）、`/bridge/`（桥接）、`/annotation/`（注解）、`/instance/`（实例）、`/imports/`、`/modules/`

## 用途

CCICO（Chinese Clinical Informed Consent Ontology）是面向中文临床知情同意书的应用本体，复用 Informed Consent Ontology (ICO)，扩展任务相关的内容语义层。发布文件为合并快照：TBox（808 个医学概念类）+ 5 份文书试点 ABox。
