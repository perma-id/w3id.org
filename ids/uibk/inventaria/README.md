## About

The [Inventaria project](https://www.inventaria.at/) developed an RDF Graph using w3id for permanent URIs.

### Abstract

The project Inventaria (University of Salzburg and University of Innsbruck) investigated inventories of Tyrolian castles and created an
RDF Graph to represent the information contained in the inventories. From the RDF Graph a registry website was created to query the information which can be accessed through w3id URIs from other applications.
