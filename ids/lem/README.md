## Project

**Location Encoding Model (LEM) 1.0**

LEM is a compact, representation-independent information model for describing the physical location of an entity. The model defines a common semantic core and mappings to multiple representations, including text, JSON, binary TLV, and YANG.

Project repository:

https://github.com/put-teleinformatics-networks/lem-location-encoding-model
