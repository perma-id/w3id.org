# /teho

Persistent namespace for the Teho ontology of work: the work-object classes and lifecycle
vocabulary, the SKOS concept schemes, the mapping sets to published standards, and the named
graphs that carry them. Published by [Teho](https://www.teho.ai/).

`https://w3id.org/teho/<path>` redirects to `https://www.teho.ai/research/ns/<path>`.

Paths in use:

| Path | Holds |
|---|---|
| `ns/work#` | the work-object ontology (classes, lifecycle tokens, relations) |
| `ns/scheme/` | SKOS concept schemes |
| `ns/mapping/` | mapping sets to published standards |
| `ns/graph/` | named-graph identifiers |
| `ns/onet/`, `ns/soc2020/`, `ns/unspsc/` | proxy identifiers for standards that publish no linked-data form of their own |
