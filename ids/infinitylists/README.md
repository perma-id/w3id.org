# /infinitylists/

Permanent address for [infinitylists](https://github.com/traitecoevo/infinitylists),
a web app for place-based species checklists
(Cornwell, Kar & Mesaglio 2025, *Applications in Plant Sciences*,
<https://doi.org/10.1002/aps3.70012>).

- `https://w3id.org/infinitylists/` redirects to the web app,
  <https://traitecoevo.github.io/infinitylists/app/>
- `https://w3id.org/infinitylists/repo` redirects to the GitHub repository
- `https://w3id.org/infinitylists/docs/` redirects to the R package documentation,
  <https://traitecoevo.github.io/infinitylists/>
