# omx: ontology metrics extension

A small OWL vocabulary for metrics, summarizability and ambiguous terms in ontologies over
tabular data. Source: https://gitlab.com/briceg/omx

- `https://w3id.org/omx#` is the namespace. `https://w3id.org/omx` redirects to the vocabulary in
  Turtle for `Accept: text/turtle`, and to the spec otherwise.
- `https://w3id.org/omx/shapes` redirects to the SHACL shapes.
- `https://w3id.org/omx/<x.y.z>` and `https://w3id.org/omx/<x.y.z>/shapes` redirect to a release.
