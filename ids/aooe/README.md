# /aooe/ — AOOE vocabulary

Permanent identifier for the **AOOE (Agent-Oriented Ontology Engineering)**
vocabulary: the terms a methodology package uses to declare its import
manifest (`aooe:importedVocabulary`, `aooe:pinnedVersion`, `aooe:termsReused`),
its Behavioral Concept Specifications (`aooe:governs`, `aooe:refines`) and its
adoption level (`aooe:AdoptionLevel`, `aooe:providesLevel`, `aooe:adoptsLevel`,
`aooe:AdoptionRecord`).

Namespace: `https://w3id.org/aooe#`. Turtle, JSON-LD and RDF/XML are served on
content negotiation; browsers are sent to the documentation page. Published
files resolve under `https://w3id.org/aooe/<file>`.

Maintained by [WordLift](https://wordlift.io). Source and documentation:
<https://github.com/wordlift/aooe>.
