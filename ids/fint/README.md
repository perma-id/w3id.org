# FINT information model

`https://w3id.org/fint/` is the permanent namespace for the FINT information
model maintained by Novari. The model describes data used for integration
across Norwegian county authorities and is being represented in LinkML.

Project resources:

- [FINT information model documentation](https://informasjonsmodell.felleskomponent.no/)
- [FINT information model source](https://github.com/FINTLabs/fint-informasjonsmodell)
- [FINT LinkML model source](https://github.com/FINTLabs/fint-informasjonsmodell-linkml)

## Redirects

The namespace root and all subordinate paths currently redirect to the FINT
information model documentation using HTTP 302. This establishes the namespace
with a working landing page while more specific LinkML schema and term
resolution rules are prepared.

For example, `https://w3id.org/fint/administrasjon/fullmakt` currently redirects
to `https://informasjonsmodell.felleskomponent.no/`.
