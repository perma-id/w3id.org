# Cocos

Permanent identifiers for the public registry of Cocos, a framework developed to apply antimicrobial resistance prediction models to bacterial sequencing samples. 
The registry describes the processing steps and models Cocos offers with the AMRF vocabulary (<https://w3id.org/amrf/>).

`https://w3id.org/cocos/` redirects to the Cocos deployment at <https://gin.us.es/cocos/>,
which serves HTML or RDF (Turtle, JSON-LD, RDF/XML, N-Triples) by content negotiation.

Source code and documentation: <https://github.com/DEAL-US/Cocos>
