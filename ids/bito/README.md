# Behavioral Interoperability Testing Ontology (BITO)

This directory provides the persistent Web identifier configuration for the
**Behavioral Interoperability Testing Ontology (BITO)**.

## Persistent Identifiers

- **Ontology IRI:** <https://w3id.org/bito>
- **Namespace:** <https://w3id.org/bito#>
- **Preferred prefix:** `bito`
- **Version IRI:** <https://w3id.org/bito/1.0.0>

## Ontology

The **Behavioral Interoperability Testing Ontology (BITO)** provides a semantic
model for ontology-driven behavioral interoperability testing. It represents
use cases, scenarios, expected behavior, observed execution evidence,
behavioral constraints, validation results, and interoperability verdicts.
