# `/pices/odis/`

Persistent identifiers for the JSON-LD directory that connects the PICES Data
Catalogue to the IOC Ocean Data and Information System (ODIS).

`https://w3id.org/pices/odis/` and every path under it redirect (302) to the
same path under <https://pices-data.github.io/odis/>, the GitHub Pages site of
the public repository [pices-data/odis](https://github.com/pices-data/odis).
The site holds one schema.org JSON-LD file per record of the PICES Data
Catalogue (the Zenodo community [`pices`](https://zenodo.org/communities/pices/)),
the catalogue and organisation nodes, and the `sitemap.xml` that ODIS harvests.
