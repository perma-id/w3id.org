# `/pices/`

Parent namespace for persistent identifiers administered by the
[North Pacific Marine Science Organization (PICES)](https://meetings.pices.int/)
(ROR: <https://ror.org/0205jhq31>).

| Identifier | Redirects to | Purpose |
| --- | --- | --- |
| [`/pices/odis/`](odis/) | <https://pices-data.github.io/odis/> | schema.org JSON-LD descriptions of the PICES Data Catalogue and the sitemap that ODIS harvests |

## Maintainers

- Brett Johnson, PICES Technical Committee on Data Exchange (TCODE), <johnson@psc.org>, GitHub: [@Br-Johnson](https://github.com/Br-Johnson)
- PICES Secretariat, <secretariat@pices.org>
- GitHub organisation [pices-data](https://github.com/pices-data), which owns the PICES data repositories
