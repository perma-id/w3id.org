# ArchiMate 4.0 in RDF

Persistent identifiers for "ArchiMate 4.0 in RDF", a draft OWL ontology and
SHACL validation set for the ArchiMate 4.0 specification (The Open Group,
C260). The relationship matrix of Appendix B.5 is published as data; ArchiMate
3.2 is supported as a compatibility profile, with mappings to earlier
ArchiMate ontologies.

ArchiMate is a registered trademark of The Open Group; this is not a
publication of The Open Group.

* Namespace: `https://w3id.org/archimate#`
* Source and issue tracker: https://github.com/jwvveen/archimate-rdf
* Sibling: [`https://w3id.org/bpmn`](https://github.com/jwvveen/bpmn-rdf), which bridges to this namespace

RDF clients (`Accept: text/turtle`) are redirected to the Turtle files;
browsers to the repository.
