Repository for redirecting to ontology for Costume Core
===================

Repository created to store the redirections of ontology files for Costume Core. 

The ontology is available in HTML, RDF/XML, TTL, N-Triple, and JSON-LD  formats:

HTML: https://ardenkirkland.com/ontologies/costumeCore/costumeCore-0.4.1/index.html

RDF/XML: https://ardenkirkland.com/ontologies/costumeCore/costumeCore-0.4.1/index.rdf

TTL: https://ardenkirkland.com/ontologies/costumeCore/costumeCore-0.4.1/index.ttl

N-Triples: https://ardenkirkland.com/ontologies/costumeCore/costumeCore-0.4.1/index.nt

JSON-LD: https://ardenkirkland.com/ontologies/costumeCore/costumeCore-0.4.1/index.jsonld

All files were generated using LODE 2.0 from https://opencitations.github.io/lode/
