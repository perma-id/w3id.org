## Redirect for FAIR Testing Services

Legacy "Gen2" FAIR Tests (used by the FAIR Evaluator) are hosted on server operated by FAIR Data Systems S.L., Madrid.
Newer FAIR Tests, authored within the OSTrails project for use with the FAIR Champion, are hosted on a server kindly donated from TU Wien.
