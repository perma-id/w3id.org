# Open Synth Descriptors (OSD)

Permanent identifiers of the Open Synth Descriptors format: its JSON Schemas per version, its vocabulary of roles and its register of extensions.

- Project: https://github.com/roomi-fields/open-synth-descriptors
- `https://w3id.org/osd/<version>/<kind>.schema.json`
- `https://w3id.org/osd/vocabulary/<n>/<file>.json`
- `https://w3id.org/osd/extensions`
