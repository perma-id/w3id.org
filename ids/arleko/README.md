# /arleko/

Permanent identifiers for AR-LEKO (Argentine Legal Knowledge Ontology), an OWL 2 ontology of Argentine legal norms.

- `https://w3id.org/arleko` redirects to the current ontology.
- `https://w3id.org/arleko/1.3.0` redirects to version 1.3.0.
- `https://w3id.org/arleko/vocab` redirects to the same document, which defines the controlled vocabularies.

Documentation: <https://ar-leko.github.io/ar-leko-ontology/>

Repository: <https://github.com/ar-leko/ar-leko-ontology>
