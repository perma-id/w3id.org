# Studium vocabulary

Permanent identifiers for the vocabulary of Studium, which turns sources you trust into adaptive lessons that you
can play in VS Code or through your own AI assistant. Published by the Holobiomics Lab (CNRS / Université Côte
d'Azur).

## Namespaces

* `https://w3id.org/studium#` — Studium vocabulary terms. Version 0.1 names the scene types of a lesson bundle
  (`https://w3id.org/studium#quiz`, `#reproduction`, …). Redirects to
  https://holobiomicslab.cnrs.fr/ns/studium, which negotiates HTML, Turtle, JSON-LD and RDF/XML.
