# /restep/

Permanent identifiers for the Restep specification, a profile for HTTP + JSON
APIs: its profile URIs, error types and JSON Schemas.

`https://w3id.org/restep/` and everything under it redirects to
<https://restep.wubytes.com/>, preserving the path. For example,
`https://w3id.org/restep/1/schema/discovery.json` redirects to
<https://restep.wubytes.com/1/schema/discovery.json>.

- Specification: <https://restep.wubytes.com/1/>
- Source and tools: <https://github.com/restep-spec>
