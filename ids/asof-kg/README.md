# AsOf-KG

Permanent IRIs for the AsOf-KG ontology, a bitemporal (valid time and record time) extension for Biolink knowledge graphs.

- Ontology: https://w3id.org/asof-kg/ontology
- Source: https://github.com/scrollashlab/asof-kg
