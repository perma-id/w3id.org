# /akso/

Permanent identifiers for AKSO: Agile Knowledge Structure Ontology.

`https://w3id.org/akso/ontology` redirects RDF/XML clients to the ontology file and everything else to <https://github.com/hajarchnok/akso>. Versioned IRIs such as `https://w3id.org/akso/ontology/1.0.0` redirect to the matching release.

Documentation: <https://github.com/hajarchnok/akso>
