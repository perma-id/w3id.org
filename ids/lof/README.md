   # Legal Ontologies Foundry (LOF)

   Persistent identifiers for the Legal Ontologies Foundry, a collaborative
   initiative developing interoperable, BFO-grounded ontologies for the legal
   domain.

   Homepage: https://legal-ontologies-foundry.github.io/

   The `.htaccess` in this directory is generated from the Foundry registry
   and should not be edited by hand.
