# Agent Memory

Persistent identifiers for the Agent Memory ontologies: a bitemporal record
model and vocabularies for agent memory, work, and software.

| Identifier | Module |
|---|---|
| `https://w3id.org/agent-memory/temporal#` | Temporal records |
| `https://w3id.org/agent-memory/memory#` | Agent memory |
| `https://w3id.org/agent-memory/work#` | Work |
| `https://w3id.org/agent-memory/software#` | Software |

Each module IRI returns Turtle to RDF clients and the HTML documentation
otherwise. `<module>/<version>` returns that tagged release, and
`temporal/shapes` and `memory/shapes` return the SHACL shapes.

Source: https://github.com/eljeffeg/memory-ontology
