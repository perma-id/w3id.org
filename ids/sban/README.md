# SBAN

Permanent identifier for SBAN (SHACL annotations for BI tools), a small
vocabulary of annotation properties that tune how BI tools present RDF data
described by SHACL shapes. It is read by
[this SPARQL driver](https://github.com/jhisse/metabase-sparql-driver).

## Identifiers

| Identifier | What it is |
|---|---|
| `https://w3id.org/sban/ns#` | The vocabulary namespace. `https://w3id.org/sban/ns` resolves to its Turtle document. |
| `https://w3id.org/sban` | The project. |

Not related to OpenLink Virtuoso's SPARQL-BI extensions.
