# BaseTwin

Permanent identifiers for BaseTwin, an open-source (Apache-2.0) digital twin core built on NGSI-LD.

| Identifier | Redirects to |
|---|---|
| `https://w3id.org/basetwin/context/v1.jsonld` | JSON-LD context, version 1 (append-only) |
| `https://w3id.org/basetwin/ns` | vocabulary page of the `bt:` terms (namespace `https://w3id.org/basetwin/ns#`) |
| `https://w3id.org/basetwin/` and anything else | public landing page |

The targets are hosted on GitHub Pages of https://github.com/ngdovan/basetwin-context.
