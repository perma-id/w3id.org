# /kennra/

https://w3id.org/kennra/ is the namespace of the Kennra Semantic Model, a small vocabulary for customer data: parties, relationships, claims, activities, commitments, consent and purposes. It maps to schema.org, JSContact (RFC 9553), W3C Org, PROV-O and DPV.

Everything under https://w3id.org/kennra/ redirects to the documentation at https://kennra.com/docs/semantic-model.

Examples:

- https://w3id.org/kennra/v1/Party
- https://w3id.org/kennra/v1/Relationship
