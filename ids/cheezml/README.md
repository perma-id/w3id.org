# /cheezml/

Permanent identifiers for CheezML, one record vocabulary for CubbyLLM, MoWM and CubeLang.

`https://w3id.org/cheezml/` redirects to <https://ns.grillcheeseai.com/cheezml/>.

- `https://w3id.org/cheezml/core`, `/cubby`, `/mowm` and `/cubelang` are content-negotiated (303): HTML, Turtle,
  JSON-LD or RDF/XML.
- `https://w3id.org/cheezml/core/v0.1` (and the same for each module) is that version.
- `https://w3id.org/cheezml/shapes` is the SHACL shapes, in Turtle.
- Any other path, such as `https://w3id.org/cheezml/context.jsonld`, goes to the file of that name (302).

Source: <https://github.com/Grillcheese-AI/cheezml>
