# /agent-passport/

Permanent identifiers for the **Agent Passport** format: an open, issuer-neutral W3C Verifiable Presentation that carries an
AI agent's mandate, record and binding blocks from three independent issuers.

| Identifier | Target |
|---|---|
| `https://w3id.org/agent-passport/envelope/v1` | the envelope's JSON-LD context |
| `https://w3id.org/agent-passport/binding/v1` | the binding block's JSON-LD context |
| `https://w3id.org/agent-passport/` (anything else) | the specification repository, https://github.com/1909-Works/agent-passport |
