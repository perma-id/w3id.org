FIDERE ecosystem
=========================

Physical Trust Extension (PTX) ontology of the FIDERE Gaia-X extension.

Homepage:
* [PTX documentation](https://fidere-extension-sprint-sep-oct-2026-42df91.gitlab.io/ptx_criteria/)
* [GitLab repository](https://gitlab.com/gaia-x/lab/gaia-x-danube-components/gaia-x-local-extensions/fidere-extension)

Redirections:
* `ptx`
  * with `Accept: text/turtle` returns the OWL ontology
  * with `Accept: application/ld+json` returns the JSON-LD context
* `ptx/shapes`
  * with `Accept: text/turtle` returns the SHACL shapes
* Any other request redirects to the PTX documentation
