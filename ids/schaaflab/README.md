# Schaaf Lab

Permanent identifiers maintained by the Schaaf Lab (Genetics of Neurodevelopmental
Disorders), Institute of Human Genetics, Heidelberg University, Germany.

<https://www.klinikum.uni-heidelberg.de/humangenetik/forschung/genetik-neurologischer-entwicklungsstoerungen/>

## Identifiers

| Identifier | Target |
|---|---|
| `https://w3id.org/schaaflab` | Research group homepage |
| `https://w3id.org/schaaflab/mfap` | MfAP variant analysis pipeline |
| `https://w3id.org/schaaflab/sys-severity-calculator` | Schaaf-Yang syndrome severity score calculator |

Both applications are cited in peer-reviewed publications. Redirects use 302
rather than 301 because the applications are expected to move to institutional
hosting, and cached permanent redirects would outlive the change.
