# /geochem/metadata

**Name of the project:** geochemBuildingBlocks, the geochemistry analytical-product metadata profiles (https://github.com/amds-ldeo/geochemBuildingBlocks)

**Description:** redirects for the profile conformance URIs that metadata records declare in `dcterms:conformsTo`:

    https://w3id.org/geochem/metadata/profiles/1.1/{name}

The `1.1` is the CDIF version the profile is built on. 66 profiles are registered. Each URI redirects to the building block at the repository tag `profiles-1.1`: the resolved JSON Schema for a JSON request or `/schema`, the SHACL rules for `/shacl` (32 profiles have them), and the block's folder on GitHub otherwise.
