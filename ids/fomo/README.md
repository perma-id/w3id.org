# Federated Open Manufacturing Ontologies (FOMO)

A manufacturing ontology network built around the ISA-95-based [manufacturing ontology](https://w3id.org/fomo/manufacturing), developed and maintained by [FlandersMake@UGent - ISyE](https://w3id.org/isye), a [Ghent University](https://www.ugent.be/en) core lab at [Flanders Make](https://www.flandersmake.be/en).

FOMO was previously published as ISyE Manufacturing Ontologies (IMO) under [w3id.org/imo](https://w3id.org/imo).
