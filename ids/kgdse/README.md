# /kgdse/

Permanent identifiers for **KG-DSE**, a traceable evidence graph of dataset use in
knowledge graph research (a systematic mapping study). The graph links research
categories, subtasks and datasets to the exact location of the evidence in the
literature.

- Website: https://beefacedata.github.io/kgdse/
- Source and data (CC BY 4.0; code MIT): https://github.com/BeefaceData/kgdse

## Redirects

- `https://w3id.org/kgdse/`: the website; Turtle and N-Triples clients get the graph.
- `https://w3id.org/kgdse/vocab` and `https://w3id.org/kgdse/shapes`: the vocabulary and the SHACL shapes (Turtle).
- `https://w3id.org/kgdse/<kind>/<id>` (for example `dataset/KGD-0001`, `record/B01-R001`,
  `subtask/CMP-01`): the resource's page on the website; Turtle and N-Triples clients get the graph.
