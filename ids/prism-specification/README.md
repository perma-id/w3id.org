# /prism-specification/

Permanent identifiers for the terms of the PRISM specification (a BIDS-compatible format for psychology and neuroscience
data): `https://w3id.org/prism-specification/terms/<modality>/<local-id>` names the term `prism:<local-id>`.

`https://w3id.org/prism-specification/` redirects to <https://github.com/MRI-Lab-Graz/prism-specification>.

This is not the `/prism/` identifier, which belongs to a different project (an EU AI Act compliance ontology).

Documentation: <https://github.com/MRI-Lab-Graz/prism-specification>
