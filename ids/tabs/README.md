# TABS

Persistent identifiers for [TABS](https://uva_ibed_piac.gitlab.io/tabs/) (Temporal Altitudinal Biogeographic
Shifts), an R package and open datasets to reconstruct how islands and mountain habitats change through time.

| Identifier | Redirects to |
|---|---|
| https://w3id.org/tabs/ | the TABS website: documentation and vignettes |
| https://w3id.org/tabs/gitlab | the source code on GitLab |
| https://w3id.org/tabs/tibs-tabs-workshop | the TIBS-TABS workshop material (The International Biogeography Society) |
| https://w3id.org/tabs/tips-for-tabs-lecture | the "Tips for TABS" lecture (Palaeoverse, YouTube) |

The datasets, the package and the paper have DOIs of their own and are not redirected here.
