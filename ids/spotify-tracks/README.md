# /spotify-tracks/

Permanent identifiers for the Spotify Tracks Linked Data project (MEIC, FEUP).
- `https://w3id.org/spotify-tracks/terms/` redirects to the minted vocabulary (OWL, Turtle).
- `https://w3id.org/spotify-tracks/shapes/` redirects to the SHACL shapes (Turtle).
- Anything else directs to the REPO.
