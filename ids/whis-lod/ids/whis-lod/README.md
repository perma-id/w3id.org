# /whis-lod/

Permanent identifiers for whis-lod, the World Heritage Irrigation Structures (WHIS) in Japan as Linked Open Data.

`https://w3id.org/whis-lod/` redirects to <https://ysh17-hub.github.io/whis-lod/>.
Facility IRIs (`resource/WHIS-JP-nnn`), the vocabulary (`ontology`) and the dataset (`dataset`) are content-negotiated (Turtle, JSON-LD or HTML).

Documentation: <https://github.com/ysh17-hub/whis-lod>
