# Produpass

Permanent identifiers for Produpass, a tool published by BrainOps SAS (France) for the battery passport of
Regulation (EU) 2023/1542.

- `https://w3id.org/produpass/batterie/vK/point-NN`: definition of a data point of the battery passport (version K
  of the definition, point NN), redirected to `https://id.produpass.com/definitions/batterie/vK/point-NN/`.
  An identifier is never reused; a new version of a definition receives a new identifier.
- `https://w3id.org/produpass/batterie`: index of the definitions.
- `https://w3id.org/produpass/symboles/v1/collecte-separee.svg`: separate collection symbol, redirected to
  `https://id.produpass.com/_produpass/collecte-separee.svg`.
