# BIMxel Ontology — https://w3id.org/bimxel

**Permanent URL:** `https://w3id.org/bimxel#` — the trailing `#` is only
used when minting term URIs (e.g. `https://w3id.org/bimxel#Sensor`). A URL
fragment is never sent over HTTP, so `https://w3id.org/bimxel`,
`https://w3id.org/bimxel/`, and `https://w3id.org/bimxel#` all resolve
through the exact same redirect below.

**Redirects to:** https://ontologia-bimxels-185727.mygitpages.cs.upc.edu/
(GitLab Pages, hosted by the Universitat Politècnica de Catalunya). The
`.htaccess` in this folder always points at whatever is currently published
there — it has no notion of a specific ontology version, so it never needs
to be updated when a new revision is released.

## About

BIMxel is developed within the **GreenBIMxels** project, led by the
Universitat Politècnica de Catalunya (UPC). Source repository (UPC-internal
GitLab): https://mygitlab.cs.upc.edu/GreenBIMxels/ontologia-BIMxels

### Abstract

The BIMxel ontology acts as a semantic bridge between widely adopted
ontologies and standards—including BOT, SAREF, SAREF4ENER, PROV-O, DCAT,
QUDT, GeoSPARQL, and BEO—to support the interoperable generation of building
digital twins. BIMxel integrates BIM data, sensors, measurements, external
data services, and provenance information into a unified knowledge graph,
enabling continuous monitoring of building operation and energy
consumption.
