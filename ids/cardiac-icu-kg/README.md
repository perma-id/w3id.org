# /cardiac-icu-kg/

Permanent identifiers for a provenance-layered knowledge graph for cardiac
surgery and intensive care.

`https://w3id.org/cardiac-icu-kg/` and every IRI below it redirect (303) to
<https://zenodo.org/records/23944677>, the Zenodo concept record of the
archived release. It always resolves to the latest version.

Code: <https://gitlab.com/rnkous/cardiac-icu-kg>
