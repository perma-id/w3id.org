# /solidhealthconnect/

Permanent identifiers for [Solid Health Connect](https://github.com/dorschre/SolidHealthConnect),
an Android app that exports Health Connect records to a Solid pod as RDF.

| Identifier | Redirects to |
|---|---|
| `https://w3id.org/solidhealthconnect/ontology`, `shapes`, `category/`, `datatype/`, `health-connect-enum/`, `property/`, `measurement-model/`, `observable-property/`, `source-record/` | [Health ontology and SHACL shapes](https://renedorsch.solidcommunity.net/apps/solid-health-connect/solidhealthconnect-health.ttl) |
| `https://w3id.org/solidhealthconnect/health-connect`, `exercise-type/`, `exercise-segment-type/`, `sleep-stage/` | [Health Connect vocabulary](https://renedorsch.solidcommunity.net/apps/solid-health-connect/health-connect-vocab.ttl) |
| `https://w3id.org/solidhealthconnect/ontology/{version}` | Released ontology, e.g. [0.2](https://renedorsch.solidcommunity.net/apps/solid-health-connect/0.2/solidhealthconnect-health.ttl) |
| `https://w3id.org/solidhealthconnect/health-connect/{version}` | Released vocabulary, e.g. [0.2](https://renedorsch.solidcommunity.net/apps/solid-health-connect/0.2/health-connect-vocab.ttl) |

All redirects use HTTP 303. Other paths return 404.
