# decision

`https://w3id.org/decision` identifies a small vocabulary (prefix `dec:`) for the characteristics of a decision put to
a person: its nature, what is at stake, the oversight it required and its outcome. It is a vocabulary, not a standard.
The identifier redirects to the vocabulary's description in its repository (to its Turtle file when `text/turtle` is
asked for), and `https://w3id.org/decision/context.jsonld` to its JSON-LD context.

Maintainer: Laurent Lemonnier (GitHub: Laurent-Lemonnier).
