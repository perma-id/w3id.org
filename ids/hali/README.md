# /hali/

Permanent identifiers for the namespace of [hali](https://github.com/natemarks/hali), an open-source command-line tool that keeps a SKOS/OWL/SHACL description of local files.

`https://w3id.org/hali` is the ontology IRI, and its terms are `https://w3id.org/hali#…`. With `Accept: text/turtle` it redirects to the core ontology, <https://raw.githubusercontent.com/natemarks/hali/main/src/ontology/core.ttl>; otherwise it redirects to the project page, <https://github.com/natemarks/hali>. Other names under `/hali/` (graph names, media types) redirect to the project page.

Documentation: <https://github.com/natemarks/hali>
