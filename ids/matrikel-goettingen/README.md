# /matrikel-goettingen/

Permanent identifiers for the digital edition of **Die Matrikel der Georg-August-Universität zu
Göttingen 1734–1837** (the printed matriculation register, ed. Götz von Selle 1937): 39,177 entries,
machine-read, checked against the page images and parsed into fields, with a permanent identifier and
an image clipping per entry. Data CC BY 4.0; archived versions with DOI at Zenodo (from version 1.0).

`https://w3id.org/matrikel-goettingen/` redirects, path preserved, to
<https://hassmann.com/research/matrikel-goe/>.

- `https://w3id.org/matrikel-goettingen/eintrag/22761` — one entry; the identifier is the matriculation
  number of the print and never changes
- `https://w3id.org/matrikel-goettingen/daten/` — downloads of every version
- `https://w3id.org/matrikel-goettingen/doi` — the dataset's concept DOI (from version 1.0)

Documentation: <https://hassmann.com/research/matrikel-goe/doku>

The second volume of the register (1837–1900) is planned for a later version under the same namespace.
