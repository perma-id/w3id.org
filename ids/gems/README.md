# /gems/

Permanent identifiers for GEMS, a database of enteric methane measurements from cattle made with GreenFeed systems.

- `https://w3id.org/gems/ontology` redirects to the GEMS ontology: the Turtle file for RDF clients, the documentation for browsers.
- `https://w3id.org/gems/ontology/<version>` redirects to one release, e.g. `0.2.0`.
- `https://w3id.org/gems/id/...` names records in the GEMS knowledge graph and redirects to the documentation.

Documentation: <https://github.com/pcn287/gems-ontology>
