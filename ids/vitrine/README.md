# /vitrine/

Permanent identifiers for the [Vitrine](https://github.com/aleph-garden/vitrine)
vocabulary. Vitrine is a rendering layer: a resource has an address, a rule
table names a view, and the view returns HTML.

The vocabulary carries the terms a rendering layer has to mint because no
registered vocabulary names a view or the rule table that selects one. Which
views exist is a separate set of resources and is not named here.
