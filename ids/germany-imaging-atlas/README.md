# /germany-imaging-atlas/

Permanent identifier for the Germany Imaging Atlas, an interactive research
dashboard of inpatient CT and MRI utilisation across 624 diagnoses in Germany,
2005–2024.

`https://w3id.org/germany-imaging-atlas/` redirects to
<https://hamed-kalak.github.io/germany-imaging-atlas/>.

Documentation: <https://github.com/Hamed-kalak/germany-imaging-atlas>
