# /caselinker/

Permanent identifiers for [CaseLinker](https://github.com/mrinaalr/CaseLinker).

`https://w3id.org/caselinker/` redirects to <https://caselinker.up.railway.app/>.

`https://w3id.org/caselinker/resource/…` names a case, agency, platform, or location. `https://w3id.org/caselinker/ns/provenance#` names the provenance terms. Both redirect to <https://caselinker.up.railway.app/patterns>.

Documentation: <https://caselinker.up.railway.app/patterns>
