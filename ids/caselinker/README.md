# /caselinker/

Permanent identifiers for [CaseLinker](https://github.com/mrinaalr/CaseLinker).

`https://w3id.org/caselinker/` redirects to <https://caselinker.up.railway.app/>.

`https://w3id.org/caselinker/resource/…` names a case, agency, platform, or location. `https://w3id.org/caselinker/ns/provenance` names the provenance vocabulary. Each redirects with 303 See Other to the same path on <https://caselinker.up.railway.app/>, which serves a description of that resource.
