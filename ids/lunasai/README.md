# /lunasai/

Permanent identifiers for the LunasAI Knowledge Graph, a clinical knowledge
graph linking biomedical literature with US medical coding, coverage, drug,
device, trial and provider data.

`https://w3id.org/lunasai/kg/<kind>.<id>` names one entity in the graph. It is
the URI format for the `lunasai` prefix requested from the Bioregistry.

- `kg/npi.<npi>` redirects to the NPPES NPI Registry entry for that provider.
- Every other identifier, and `https://w3id.org/lunasai/`, redirects to
  <https://lunas.health/about> until per-record pages exist.
