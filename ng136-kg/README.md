# ng136-kg

Permanent identifiers for an ontology and knowledge graph built from the NICE guideline NG136 (hypertension in adults), made for an MSc dissertation.

* `https://w3id.org/ng136-kg#...` are the ontology terms (classes and properties).
* `https://w3id.org/ng136-kg/rec/...`, `/concept/...`, `/status/...` and `/external/...` are the identifiers of recommendations, concepts, statuses and external references.
