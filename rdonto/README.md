# RDOnto: Remote Driving Ontology

Persistent identifiers for RDOnto, an ontology of the remote driving
(road vehicle teleoperation) context: operator situation awareness and the
vehicle-to-station communication link.

## Uses

- `https://w3id.org/rdonto/{core,op,link,op-shapes,link-shapes}`: ontology IRIs
  (hash namespaces, e.g. `https://w3id.org/rdonto/op#RemoteOperator`).
  Browsers are redirected to the documentation page; other clients get Turtle.
- `https://w3id.org/rdonto/{module}.ttl`: the Turtle file.

Target: https://sanatmharolkar.github.io/RDOnto/
(source: https://github.com/sanatmharolkar/RDOnto)
