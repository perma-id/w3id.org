# /mobility-dataspace/

The official namespace of the **Mobility Data Space (MDS)** — a European data space for mobility data, operated by DRM Datenraum Mobilität GmbH.

The namespace holds the machine-readable artefacts a participant needs in order to join the MDS: the JSON-LD contexts and vocabularies of the MDS dataspace profile, the JSON Schemas of the MDS verifiable credentials, and the JSON-LD context of the MDS connector Management API.

Identifiers redirect to the specifications published from:

* [Mobility-Data-Space/mds-profile](https://github.com/Mobility-Data-Space/mds-profile) — the MDS dataspace profile, versioned as `<YYYY>/<n>`. The current version is `2026/1`.
* [Mobility-Data-Space/mds-edc](https://github.com/Mobility-Data-Space/mds-edc) — the MDS connector Management API, currently `v1`.
