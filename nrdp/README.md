# nrdp

Permanent identifiers for the national R&D portfolio MCDM ontology (method-agnostic MCDM representation layer,
Korean national R&D domain layer, classification-edition module, SHACL shapes, NTIS knowledge graph,
competency-question set).

Homepage: https://nova-choi.github.io/nrdp-ontology/
Source: https://github.com/nova-choi/nrdp-ontology

| Path | Target |
|---|---|
| /nrdp/mcdm, /nrdp/ontology, /nrdp/kosv | ontology modules (content negotiation: HTML, Turtle, RDF/XML, JSON-LD, N-Triples) |
| /nrdp/{module}/{version} | versioned ontology files |
| /nrdp/shapes/{mcdm,kosv} | SHACL shapes |
| /nrdp/data | knowledge-graph description (VoID/DCAT); instance IRIs are hash IRIs under /nrdp/data# |
| /nrdp/cq | competency-question set (HTML, CSV, JSON) |
