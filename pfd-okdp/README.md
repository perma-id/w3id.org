# PFD-OKDP

Persistent identifiers for the UNS vocabulary of the PFD-OKDP data platform.

| URI | Target |
|---|---|
| `https://w3id.org/pfd-okdp/uns/def` | ontology / vocabulary (OWL), current version |
| `https://w3id.org/pfd-okdp/uns/def/<version>` | ontology, given version (e.g. `0.1.0`) |
| `https://w3id.org/pfd-okdp/uns/ref/...` | SKOS reference data (including CPV 2008) |
| `https://w3id.org/pfd-okdp/uns/shapes` | SHACL shapes |
| `https://w3id.org/pfd-okdp/` | landing page |

Content negotiation: `text/turtle`, `application/ld+json` and `application/rdf+xml` return RDF;
any other request returns the HTML documentation.

Files are hosted at https://github.com/dibled/pfd-okdp-uns (GitHub Pages).
