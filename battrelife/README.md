# BattReLife

Persistent identifiers for BattReLife, an evidence-aware ontology for battery
second-life assessment and Digital Battery Passport support (PhD research,
ICube Laboratory, UMR 7357, Université de Strasbourg / INSA Strasbourg).

- Namespace: https://w3id.org/battrelife/
- Target: https://cyrinesoufi.github.io/battrelife/
