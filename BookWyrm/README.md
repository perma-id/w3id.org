# BookWyrm: Social Reading and Reviewing, Decentralized

BookWyrm is a social network for tracking your reading, talking about books, writing reviews, and discovering what to read next.

BookWyrm is part of the ActivityPub fediverse and uses several custom types that extend the [Activity Streams 2.0 vocabulary](https://www.w3.org/TR/activitystreams-vocabulary/#introduction).

This namespace primarily is to provide a stable identifier for our own vocabulary definitions.
