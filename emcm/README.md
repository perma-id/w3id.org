# EMCM — EthnoMusic Conceptual Model

Permanent identifiers for the EMCM ontology (an ethnomusicological extension
of CIDOC CRM 7.1.3 and LRMoo 1.1.1) and its SKOS vocabularies
(`/emcm/vocab/...`). All requests are redirected to the canonical host,
https://data.tropos.org.gr/emcm/, where content negotiation is performed.
