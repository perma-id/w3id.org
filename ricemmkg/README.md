# Rice MMKG — Rice Multimodal Knowledge Graph

Permanent identifier for the namespace of **Rice MMKG**, an OWL 2 ontology and knowledge graph for rice disease and pest diagnosis. It links diseases, pests, pathogens, symptoms, growth stages, environmental factors, treatments and management actions, with every domain assertion carrying a literature citation, and connects them to 10,407 field images from the Paddy Doctor dataset.

- **Namespace:** `https://w3id.org/ricemmkg#` — hash IRIs, e.g. `https://w3id.org/ricemmkg#Rice_Blast_Disease`
- **Version IRIs:** `https://w3id.org/ricemmkg/<version>`, e.g. `https://w3id.org/ricemmkg/0.6.1`
- **Source repository:** https://github.com/Ariful-Furqon/Rice-Multimodal-Knowledge-Graph
- **License:** CC BY 4.0

## Redirects

| Request | Client | Target |
|---|---|---|
| `https://w3id.org/ricemmkg` (and any term IRI) | Browser (`text/html`, `application/xhtml+xml`, or a `Mozilla/…` user agent) | GitHub repository page |
| `https://w3id.org/ricemmkg` (and any term IRI) | Anything else (`application/rdf+xml`, `*/*`, no `Accept` header) | Latest ontology, RDF/XML, `main` branch |
| `https://w3id.org/ricemmkg/<version>` | Any | Ontology file at git tag `v<version>` |

All redirects use HTTP 303. When HTML documentation for the ontology is published, the browser redirect will be updated to point to it.
