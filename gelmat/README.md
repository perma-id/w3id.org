# Gelmat: An Ontology for Sol-Gel Materials

Permanent identifier for the Gelmat ontology, a domain ontology for sol-gel
materials (aerogels, xerogels, and related materials), extending the Polymat
ontology (https://w3id.org/polymat/).

- Namespace: https://w3id.org/gelmat/
- Repository: https://github.com/dlr-wf/Gelmat-Ontology
- License: CC-BY-NC-4.0

The ontology IRI and term IRIs content-negotiate: RDF requests (Turtle,
RDF/XML, JSON-LD) receive the ontology file; browsers receive the HTML
documentation at https://dlr-wf.github.io/Gelmat-Ontology/. Version IRIs
(e.g. /gelmat/1.1.0) resolve to the correspondingly tagged ontology file.
